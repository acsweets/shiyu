# Shiyu Flutter app

[简体中文](README.md) · [English](README.en.md)

This directory is the Flutter root. Its parent is the Git repository. The entry point is `lib/main.dart`. Desktop floating windows live in `lib/features/desktop_stickers/`. The mobile dashboard, settings and shared controller live in `lib/features/retirement/`. Rust implements the time and earnings rules in the repository's `core/` directory.
