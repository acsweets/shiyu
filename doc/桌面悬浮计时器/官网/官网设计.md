# 时余官网 PRD

- 文档版本 v1.1
- 更新日期 2026-11-06
- 状态为需求草案。首屏定位已确认，网站与安装包的发布状态按实际验收更新。

页面尺寸、配色、组件、猫猫和拍摄要求见[官网设计规范](设计规范/README.md)。

## 1. 产品定位

**用户离开官网后，应该记得「桌面上有只猫陪我看倒计时」。**

时余是一款带手绘猫猫贴纸的桌面倒计时工具。工作时，抬眼就能看到离下班还有多久。发薪、放假等倒计时可以留在旁边，用户自己决定怎么摆、哪些要显示。今日和本月已赚是同一套浮窗里的实用功能。

首版官网解决两件事：

1. 用户能从首屏看懂猫猫、桌面浮窗和倒计时的关系。
2. 用户能找到自己设备的下载或内测入口，并看懂当前发布状态。

桌面浮窗是首页主角。移动端单独介绍原生主屏幕小组件，页面文案统一称「小组件」。品牌显示为「时余」，英文标识使用「Shiyu」，「桌面猫猫倒计时」用作产品描述。

## 2. 页面结构和用户路径

采用单页。导航使用「时余」「功能」「下载」「常见问题」，页脚提供反馈、使用说明和隐私说明。

| 顺序 | 内容 | 用户在这里要搞清楚什么 |
| --- | --- | --- |
| 1 | 首屏 | 时余长什么样，桌面上的猫猫和倒计时怎么摆 |
| 2 | 桌面浮窗 | 怎么把几个倒计时放在一起，或者拆开自由摆放 |
| 3 | 今日已赚 | 怎么看今日和本月的估算金额，什么时候可以隐藏 |
| 4 | 手机小组件 | 怎么放到手机主屏幕，手机和桌面分别是什么体验 |
| 5 | 平台下载 | 当前设备能否下载、安装或加入内测 |
| 6 | 常见问题与页脚 | 兼容性、数据保存、安装帮助、反馈 |

想直接安装的访客可以从首屏按钮或导航进入下载；想先了解功能的访客沿页面向下看，功能区末尾提供同一个下载区入口。

## 3. 首屏

**主标题**

> 桌面上有只猫，陪你看倒计时。

**说明文案**

> 抬眼就能看到离下班、发薪、放假还有多久。把常看的倒计时合在一起，或拆成小窗摆在桌面上。

**首屏画面**

- 用真实桌面浮窗和已有橘猫贴纸。画面以「距离下班」为主，右侧或下方摆一张较小的「今日已赚」浮窗，让访客一眼看到两张窗能独立摆放。
- 选用暖白背景和一套奶油黄、浅桃色的浮窗。猫贴着窗体上沿，卡片内上方是标题，下方是一行完整倒计时。应用图标放在导航品牌位。
- 截图使用示例配置，薪资画面标明「示例数据」。避免截入桌面通知、文件名或个人信息。主图替代文本说明「橘猫趴在下班倒计时浮窗上，旁边是今日已赚」。
- 桌面使用左文右图。窄屏按标题、说明、主按钮、产品图顺序堆叠，保留两张浮窗和完整计时。

**按钮**

主按钮根据平台和发布状态显示「下载 Windows 版」「下载 macOS 版」「下载 Android APK」「加入 iOS TestFlight」或「前往应用商店」。对应入口有效时直达；平台识别失败或对应平台尚未开放时显示「查看各平台状态」，跳到下载区。次入口始终为「查看所有平台」。两个入口同时指向下载区时只保留一个。页面保留四个平台的人工选择，平台识别只用于推荐。

## 4. 功能内容

| 展示标题 | 文案方向 | 素材 |
| --- | --- | --- |
| 想看什么，就放在桌面上 | 下班、放假、发薪可以合在一张窗里，也能拆开、拖动和缩放。每张窗的猫猫姿态不同，还可隐藏标题、切换配色。 | 同一组倒计时「合并」和「拆分」的真实对照图 |
| 今日已赚，想看就看 | 按自己填写的月薪和作息估算今日、本月金额。可以隐藏「今日已赚」这一项，也可以保留卡片并遮蔽金额。 | 使用示例数据的薪资卡，以及同一张卡遮蔽金额的状态 |
| 手机上，猫猫住在主屏幕 | 从系统组件图库或启动器添加卡片，可以按支持情况把几个指标放在同一张卡里，或分别添加。 | 至少一张已验证平台的真实主屏幕截图，标注平台和功能条件 |

在三段展示之后用一行清单补充支持的内容：上下班、放假、发薪、退休、生命、今日及本月已赚。桌面自定义倒计时可在功能说明中补充。生命指标沿用应用名称「静待百岁，好好生活」和「已存在世界」。

刷新说明按场景区分。桌面活跃倒计时和移动应用前台可以逐秒更新。手机系统小组件由系统安排刷新，薪资刷新频率及卡内手动刷新入口按平台、系统版本和实际发布包说明。iOS 15、16 使用固定组件，iOS 17 及以上支持编辑通用组件，官网以验收过的版本为准。

## 5. 下载与平台状态

| 平台 | 当前工程基线 | 可开放的入口与条件 |
| --- | --- | --- |
| Windows | 产品目标 Windows 10 及以上 | 安装包通过发布验收后开放下载，兼容性与架构以安装矩阵为准 |
| macOS | 工程部署目标 macOS 12 | 签名、公证和安装验证完成后开放下载，按产物标注 Intel 或 Apple 芯片 |
| Android | 工程最低 API 24（Android 7.0） | 有正式签名并通过真机安装和升级验证的 APK 后开放下载。Google Play 链接实际可用时显示 |
| iOS | 工程部署目标 iOS 15 | 有有效的公开邀请时显示 TestFlight；App Store 上架后提供商店入口。小组件差异单独说明 |

发布时，平台卡片展示经验证的系统与架构要求，以及与入口对应的渠道。直接下载同时展示真实版本、文件大小、安装说明和校验和。TestFlight 卡片说明加入步骤和测试版身份。商店链接指向该应用的真实页面。

平台状态由 Xingverse「构建管理」发布的公开数据驱动，首屏和下载区共用。每个平台独立维护状态、渠道、版本、最低系统、架构、链接和安装说明。状态支持「准备中」「公开内测」「可下载」「商店已上架」。任一入口失效时回退到该平台当前可用的入口或说明。

打开下载的前置条件见[节点 14 发布验收](../../../docs/开发计划/14-签名打包与发布验收.md)。当前工程基线用于筹备，官网最终展示以实测安装包为准。所有平台仍在准备时，官网可以展示产品和平台状态；官网对外开放与安装包对外分发分别记录。

## 6. 视觉与素材

- 沿用应用的暖白文具风。页面底色可用 `#FFFCF6`，正文和主按钮文字用深棕 `#39251A`，暖黄 `#FFB800` 用作少量强调。马卡龙配色集中在产品截图和轻量标签，下载按钮使用一致样式。
- 复用应用图标和真实猫猫素材。猫猫用于首屏和浮窗展示。动画属于增强项，保留清晰的静态首帧，遵循系统减少动态效果设置。
- 首版素材为应用图标与 favicon、首屏桌面画面、合并拆分对照、示例薪资卡、已验证的手机主屏幕截图、社交分享图。截图标注平台，使用发布候选版本并保留可复拍的示例配置。
- 统一正文和数字字重。正文、按钮与焦点状态清晰可辨；下载、导航和 FAQ 支持键盘操作。首屏图优先加载，下方图按需加载。

## 7. 常见问题与可信信息

- **我的薪资数据保存在哪里？** 薪资和个人设置保存在设备上，应用联网获取公开节假日数据。应用中的「隐藏金额」可遮住展示值。
- **今日已赚是实发工资吗？** 这是根据用户填写的月薪、应出勤日和工作时段得出的估算值。
- **我的系统能安装吗？** 引导到平台下载卡，按实际版本、系统和架构提供安装说明。
- **怎么添加手机小组件？** 按 Android、iOS 分别提供系统入口和操作步骤，说明可用的组合与刷新行为。
- **如何反馈问题？** 使用已确认的反馈入口。反馈指引提醒用户隐去截图里的个人设置和薪资。

页脚提供使用说明、隐私说明和已确认的反馈入口。版本历史可先链接到已发布记录。价格、许可、公开测试名额和上架进度等信息按确认后的实际情况填写。

## 9. 验收清单

### 页面与内容

- [ ] 首屏用「时余」和已确认的主标题。给首次访问者只看首屏，请其用一句话复述；能说出桌面、猫猫和倒计时。
- [ ] 首屏画面与真实产品一致，猫猫贴在窗沿，主倒计时完整，薪资浮窗只使用标注过的示例数据。
- [ ] 合并拆分、金额显隐、移动小组件都有对应说明和真实画面。小组件展示区按平台注明刷新与系统版本差异。
- [ ] 桌面与窄屏页面无横向溢出。手机首屏可操作主按钮，键盘可访问导航、下载入口和 FAQ，文字与按钮对比清晰。
- [ ] 隐私说明、使用说明、反馈入口及页面分享信息可访问，文案与实际能力一致。

### 下载与上线

- [ ] 分别检查 Windows、macOS、Android、iOS、未知平台及没有可用下载的情况，首屏主按钮与平台卡片状态一致。
- [ ] 每个开放的下载、邀请或商店链接都按普通访客路径实测。安装包版本、架构、最低系统和校验和与发布记录一致。
- [ ] 在「构建管理」撤回某平台入口后，访客刷新页面，首屏与下载区同时更新。
- [ ] 生产域名、托管位置和静态资源路径确认，按真实上线情况记录验收日期。已确认的反馈与隐私入口一并复查。
