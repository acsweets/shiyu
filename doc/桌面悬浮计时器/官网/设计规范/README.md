时余官网在个人站主域提供简体中文 `/shiyu/` 和英文 `/shiyu/en/`。访客从同语种的「构建」页进入，也可在官网导航切换。Xingverse 前端仓库的《M2 访客端与时余官网》负责落地与联调；应用浮窗和小组件的实际功能、平台与验收条件见[项目记录](../../../../docs/项目记录/功能现状与设计基线.md)。

实现前先确认首屏布局和素材分工，再拍摄桌面浮窗及移动主屏幕；素材就绪后按组件规范完成页面，最后用 M2 的公开状态样例和本目录的设计检查项一起验收。
