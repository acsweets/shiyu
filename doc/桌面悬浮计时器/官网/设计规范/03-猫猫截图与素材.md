# 03 猫猫、截图与素材

[设计规范总览](README.md) · [官网布局与响应式](01-官网布局与响应式.md) · [配色、字体与组件](02-配色字体与组件.md)

## 1. 角色身份与使用位置

时余猫猫是同一只手绘 Q 版橘猫。辨识点是奶油色脸、杏橘条纹、弯眼、粉桃腮红、可可棕笔触和浅色贴纸边。官网沿用应用的 2D 角色和猫头图标，保留原比例、透明边缘、尾巴和爪子。

| 姿态或图标 | 素材 | 官网角色 |
| --- | --- | --- |
| 猫头图标 | [图标前景](../../../../app/assets/brand/app_icon_foreground.png)及[图标规范](../../../../app/assets/brand/README.md) | 导航品牌位、favicon、页脚小标。导航用带浅黄底的方形品牌图标，品牌文字置于图标外 |
| 坐姿 | [character.png](../../../../app/assets/stickers/character.png) | 首屏奶油黄主窗的猫，默认最大、最清楚。它负责让访客看懂猫猫和倒计时的关系 |
| 伸懒腰 | [character-stretch.png](../../../../app/assets/stickers/character-stretch.png) | 拆分对照图的第二窗口，斜向伸展表现独立浮窗 |
| 挥爪 | [character-wave.png](../../../../app/assets/stickers/character-wave.png) | 拆分对照图中第三窗口或补充窗图，按实拍决定是否出现 |
| 蜷睡 | [character-sleep.png](../../../../app/assets/stickers/character-sleep.png) | 首屏较小的粉桃薪资窗，低矮轮廓和坐姿形成主次。薪资显隐对照沿用同一姿态 |

桌面应用的窗口槽位 1–4 依次绑定坐姿、伸懒腰、挥爪、蜷睡。首屏拍摄使用槽位 1 的「距离下班」和槽位 4 的「今日已赚」，拍摄时只保留这两窗可见。功能图允许出现更多窗口，按实际分组呈现。手机图使用系统小组件真实出现的猫猫，不另贴独立角色。下载按钮、平台状态、FAQ 行和错误提示保持干净，猫猫集中出现在品牌与真实产品画面。[原始贴纸规范](../../../../app/assets/stickers/README.md) · [桌面浮窗分组与姿态](../../../../docs/界面设计/06-桌面浮窗分组.md)

## 2. 贴边和比例

- 官网首屏使用真实窗口画面，沿用应用的窗沿接触关系。看上去像爪子、下巴或身体贴在上沿，轻压边界；猫耳、尾巴和前爪留完整。窗口标题在卡片内上方，数字一整行显示在下方。
- 如果社交图等素材要单独摆放原始透明贴纸，以可见轮廓的最低点定位。坐姿和蜷睡的透明留白不同，按正方形 PNG 的底边摆放会显得一高一低。以约 4–8px 的可见轮廓重叠为制作起点，再按画面缩放和实际窗沿复核。
- 桌面首屏图框内，主窗宽约占 48%，薪资窗约占 32%，两窗之间有明显间隙。主窗猫轮廓略大，薪资窗与主窗错位向下。手机专用构图可将次窗继续下移，贴纸可见面积按画面同比缩放。
- 猫猫不盖住标题、数字、设置入口或「示例数据」标注。展示用贴纸不响应点击。产品截图中已包含贴纸时，页面只显示这张截图。

原始四姿态均为 1254 × 1254 的透明 RGBA PNG。应用记录的画布下方透明比例分别约为坐姿 9%、伸懒腰 8%、挥爪 3%、蜷睡 17%。衍生图若裁了透明边，应以裁后文件重新对齐，检查奶油色轮廓在暖白底上没有明显白框。[姿态与透明比例源码](../../../../app/lib/features/desktop_stickers/data/sticker_cat_pose.dart)

## 3. 产品截图拍摄清单

| 素材 | 建议构图 | 必须能看清 |
| --- | --- | --- |
| `hero-desktop` | 约 3∶2。实际桌面浮窗放在干净暖色桌面背景，主窗左中、薪资右下。窗口之间保留空白 | 坐姿猫、主窗标题和完整倒计时，次窗的蜷睡猫、标题和示例金额 |
| `hero-narrow` | 约 4∶3。重新摆放两窗后拍摄，主窗偏上、次窗偏下并适当右移 | 两张窗均完整。手机宽度下保留数字、猫尾与贴边关系 |
| `desktop-grouped`、`desktop-split` | 同设备、同配置、同一组倒计时、同一背景。先合并拍一张，再拆开拍一张 | 确认是同一组内容的两种摆法。分别标注「合在一张窗」和「拆开自由摆放」 |
| `earnings-visible`、`earnings-hidden` | 同一窗口、同姿态、同尺寸、同配色。分别开启与关闭金额遮蔽 | 「今日已赚」、示例金额和遮蔽状态清楚。金额示例旁标「示例数据」 |
| `widget-android` | Android 主屏幕实际截图，可裁去无关边缘，至少保留小组件与少量主屏幕环境 | 小组件位置与内容可辨，图注明确 Android。iOS 画面在对应版本验收后补齐 |
| `og-shiyu` | 1200 × 630。暖白底，左边品牌与短标题，右边复用主窗和坐姿猫 | 缩略展示时仍能认出「时余」、橘猫和倒计时 |

拍摄用本地示例配置。保持浮窗标题打开，主窗保留产品当前的设置图标。系统桌面避免真实通知、账号头像、文件名、可识别壁纸和私人金额；使用干净的演示桌面。截图后只做留白裁切、画布排版和必要的隐私处理，保持窗口自身配色、文字、比例和应用行为真实。

移动端素材优先拍摄已验收的 Android 系统主屏幕。图注按实际设备、系统和组件行为标注，薪资刷新用语依据对应版本的实测。Android 组合与刷新以及 iOS 的复核范围见[应用验收记录](../../../../docs/验收记录/13/README.md)。

## 4. 素材交付约定

| 文件类型 | 建议尺寸和格式 | 使用规则 |
| --- | --- | --- |
| 品牌图标 | 透明或带品牌底色的 PNG，提供导航 1× 和 2×；favicon 16、32px | 在浏览器标签和 32px 导航尺寸检查猫头是否清晰。使用品牌原件衍生 |
| 首屏图 | WebP，桌面建议 768 与 1280px 宽；窄屏建议 480 与 768px 宽 | 按视口选图，保留宽高比。建议单张 ≤220KB，优先保证猫猫轮廓和数字清晰 |
| 功能图 | WebP，单张宽度约 720–1080px，窄屏使用较小变体 | 截图对照按统一宽度、色温与留白处理。首屏之外按需加载 |
| 独立角色图 | 原始 PNG 留档；网页另用时导出带透明度的 WebP 或 PNG | 保留贴纸描边和 Alpha。只按需导出实际使用的角色及尺寸 |
| 分享图 | 1200 × 630，JPEG 或 PNG | 包含品牌与主窗，图上文字控制在简短范围。上传后检查社交分享预览 |

网页使用的衍生素材放入 Xingverse 前端仓库的时余素材目录，构建时从该仓库独立读取。登记素材 ID、应用 commit 或版本、平台与设备、拍摄配置、文件宽高、大小和用途。源图与演示配置保留在时余项目的素材交付记录中。

- 首屏图替代文本建议为「橘猫趴在下班倒计时浮窗上，旁边是今日已赚」。
- 合并、拆分与薪资对照用各自简短图注或替代文本表达差异，避免同一描述被读两遍。
- 品牌图标旁已经有「时余」文字时，图标可用空替代文本。装饰性贴纸与背景也采用空替代文本。

## 5. 素材验收

- [ ] 首屏主窗为奶油黄，次窗为粉桃色，坐姿与蜷睡清晰，猫贴窗沿且无裁耳、裁尾、叠贴。
- [ ] 桌面和手机首屏都能看清完整倒计时，两窗主次关系一致，薪资画面有示例标注。
- [ ] 合并拆分与金额遮蔽对照使用同一组配置，图片说明和实际应用行为一致。
- [ ] 手机图确实来自系统主屏幕，平台与刷新文案有对应验收依据。
- [ ] 图片已登记来源、尺寸、压缩结果与替代文本，2× 屏幕和慢网下主要信息可辨认。
