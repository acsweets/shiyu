## 📋 第一期范围（最终版）

### 核心功能

#### 1. 6大计时功能 ✅
- 生命倒计时
- 上下班状态
- 实时薪资（今日已赚 + 本月已赚）
- 发薪日倒计时
- 下次放假倒计时
- 退休倒计时

#### 2. 薪资计算 ✅
- **输入**: 仅月薪（不做年薪输入）
- **显示**: 时薪自动计算（月薪÷工作日÷工作时长）
- **精度**: Decimal精确计算，无浮点误差
- **税前税后**: 双输入，用户选择显示口径

#### 3. 发薪规则 ✅
- 每月固定日
- 每月最后工作日
- 每月两次发薪
- 遇休息日可选：顺延/提前/不调整

#### 4. 工作日设置 ✅
- 7个复选框选择每周工作日
- 固定双休（不做大小周轮换）
- 默认值由地区提供

## 📦 技术实现

### 核心架构
```
Rust Engine (唯一实现)
    ↓ flutter_rust_bridge
Flutter (桌面+移动)
    ↓ UniFFI
iOS/Android Widget (原生)
```

### 关键技术
- **核心库**: Rust + jiff (时区) + rust_decimal (精度)
- **桌面UI**: Flutter Desktop + window_manager + tray_manager
- **移动UI**: Flutter Mobile + 响应式布局
- **小组件**: SwiftUI (iOS) + Glance (Android)
- **多语言**: Flutter intl + ARB文件
- **macOS全屏**: SkyLightWindow或NSApplicationActivationPolicyAccessory
- **资源包**: .timerpack格式，JSON描述 + 安全校验
