## 一、核心功能需求（PRD第4章）

### F1 生命倒计时 ✅

**需求闭环**:
- [x] 输入：出生日期+时刻、预期寿命（年，一位小数）
- [x] 输出：剩余秒数，可切换格式（天/周/周末/年月日时分秒）
- [x] 边界：超过预期寿命显示提示，不显示负数
- [x] 边界：2月29日出生在非闰年按2月28日

**技术方案**:
- 使用jiff日期运算库
- 死亡时刻 = 出生时刻 + 预期寿命（日历年加法）
- 剩余秒数 = 死亡时刻 - 当前时刻

**状态**: ✅ 完全闭环

### F3 实时薪资 ✅

**需求闭环**:
- [x] 每秒薪资 = 月薪 ÷ 当月应出勤天数 ÷ 每日有效工作秒数

- [x] 税前/税后双输入，用户选择显示口径
- [x] 今日已赚 + 本月已赚
- [x] 隐藏金额开关 + 全局快捷键
- [x] 支持月薪 ✅
- [x] 时薪展示：自动计算（月薪÷工作日÷工作时长）✅
- [ ] 年薪输入：不做 ✅（用户自己换算）
- [ ] 带薪假/无薪假（P1）✅

**技术方案**:
- rust_decimal保证精度
