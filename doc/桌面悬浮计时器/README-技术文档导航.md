## 🔑 关键技术点

### 1. 核心架构

```
Flutter (桌面+移动)
      ↓ flutter_rust_bridge
Rust Engine (唯一业务实现)
      ↓ UniFFI
iOS/Android Widget (原生)
```

### 2. 核心优势

- **计算正确性**: Rust一次实现，所有端结果一致
- **跨平台一致**: Flutter自绘，Windows和macOS视觉统一
- **性能保证**: Rust高效，Decimal精确
- **可扩展性**: 核心库可复用到后续任何平台

### 3. 核心挑战

| 挑战 | 可行性 | 解决方案 |
|------|--------|----------|
| macOS全屏显示 | ✅ 已验证 | SkyLightWindow或NSApplicationActivationPolicyAccessory |
| 节假日数据时效 | ✅ 可控 | 手动导入 + 降级规则 |
| 8国语言翻译 | ✅ 标准流程 | 专业翻译服务 |
| 跨平台一致性 | ✅ Flutter特性 | 截图对比验证 |
