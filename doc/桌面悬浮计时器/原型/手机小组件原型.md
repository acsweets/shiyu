# 手机小组件原型

版本：v0.1（讨论稿）  
适用：iOS WidgetKit / Android Glance 或 RemoteViews  
依据：`../最终确认-可以开始开发.md`

## 小组件类型

一期包含两类：倒计时类（系统计时器走秒）与薪资类（约每分钟更新）。组件独立读取共享设置与节假日数据，通过同一 Rust 核心计算，不依赖主应用运行。

## 倒计时：紧凑尺寸

```text
┌───────────────────────┐
│ 距离下班               │
│       02:14:33         │
│ 周三 · 18:00 下班      │
└───────────────────────┘
```

- 允许用户选择：距离下班、距离放假、距离发薪、距离退休。
- 主数字由系统时间线驱动显示；目标状态变化后更新标签，例如“午休结束”“放假中”。
- 点击打开应用对应指标详情。

## 倒计时：圆形尺寸（平台支持时）

```text
      ╭─────────╮
     │ 02:14:33 │
     │  距离下班 │
      ╰─────────╯
```

- 单指标展示，适合系统提供的圆形/小尺寸槽位。
- 不在圆环上暗示未定义的比例进度；圆环仅作视觉边界或由系统模板处理。
- 不可用或文字空间不足时回退到紧凑矩形布局。

## 倒计时：宽尺寸

```text
┌───────────────────────────────────────┐
│ 距离下班                  距离放假     │
│ 02:14:33                 23 天        │
│ 下班时间 18:00            下次休息 7/12│
└───────────────────────────────────────┘
```

- 宽尺寸可展示一个主指标和一个辅助指标；不支持的系统尺寸仅展示用户选择的主指标。
- 小组件配置选择主指标；宽尺寸辅助指标由用户选择或使用冻结默认顺序中的下一项。

## 薪资小组件

```text
┌────────────────────────┐
│ 今日已赚                │
│ ¥375.00                │
│ 约 1 分钟前更新         │
└────────────────────────┘
```

宽尺寸示例：

```text
┌───────────────────────────────────────┐
│ 今日已赚                 本月已赚      │
│ ¥375.00                 ¥8,420.00     │
│ 约 1 分钟前更新                         │
└───────────────────────────────────────┘
```

- 用户选择显示今日已赚、本月已赚或两者（取决于组件尺寸）。
- 按所选税前/税后口径与金额精度展示。
- 隐藏金额状态同步应用设置，显示 `****`；点击进入应用后可查看。
- 明示“约 X 分钟前更新”，不使用逐秒跳动动画或暗示实时准确。
- 午休、下班后或休息日金额按计算规则保持不变；组件不得自行累加。

## 系统添加与配置流程

```text
主屏长按 → 添加小组件 → 选择计时器 → 选择尺寸
                                      ↓
                               选择指标/配置
```

- iOS 使用系统小组件编辑与配置流程；Android 遵循启动器小组件添加和 resize 能力。
- 若平台支持配置意图，提供指标选择；否则从应用“小组件”设置页选择，并提示添加后可返回调整。
- 不在应用中伪造系统级小组件预览或主屏拖放交互。

## 状态与异常

- 缺少必需设置：显示“请完成设置”，点击进入对应表单。
- 节假日数据缺失：采用每周工作日降级，并在组件上提供简短数据状态标记；空间不足时在应用中说明。
- 应用设置更新后：请求系统刷新组件；实际生效时间遵循平台刷新策略。
- 组件数据过期：薪资组件显示最后更新时间；倒计时依据系统时间线更新，必要时触发重算。
- 深色/浅色模式跟随系统；文字保持高对比，避免依赖皮肤资源造成不可读。

## 不纳入一期

- 用户自定义脚本或自由拖拽组件内部元素。
- 保证薪资小组件秒级刷新。
- 通知、锁屏实时活动等未冻结能力。
