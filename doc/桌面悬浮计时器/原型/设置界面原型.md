# 设置界面原型

版本：v0.1（讨论稿）  
依据：`../最终确认-可以开始开发.md`  
状态：原型讨论中；功能范围以冻结稿为准。

## 页面结构

桌面端与移动端共用设置分组和业务字段。桌面端增加悬浮窗与系统行为设置；移动端不显示不适用的窗口选项。设置修改后立即生效并自动保存。

```text
设置
├─ 个人信息
├─ 作息与薪资
├─ 日期与假期
├─ 悬浮窗与显示       桌面端
├─ 小组件             移动端
└─ 通用
```

## 个人信息

```text
个人信息

出生日期             [ 年-月-日      ]
出生时间             [ 00:00         ]  可选
预期寿命             [ 100 ] 年
退休日期             [ 年-月-日      ]
```

- 出生日期必填；出生时间默认 `00:00`。
- 预期寿命支持一位小数，默认 100 年。
- 退休日期由用户直接填写。

## 作息与薪资

```text
作息
上班时间             [ 09:00 ]
下班时间             [ 18:00 ]
午休                 [ 开关：开 ]
午休时间             [ 12:00 ] 至 [ 13:00 ]

每周工作日           [一] [二] [三] [四] [五] [六] [日]

薪资
税前月薪             [                 ]
税后月薪             [                 ]  选填
显示口径             (•) 税前  ( ) 税后
币种                 [ CNY · ¥       ▾ ]
金额精度             [ 2 位小数       ▾ ]
```

- 工作日按地区默认值预选，支持勾选每周工作日；不提供大小周设置。
- 下班时间必须晚于上班时间；非法输入就地提示并保留上次合法值。
- 选择税后口径前需填写税后月薪；否则该选项不可选。
- 金额精度支持 2–4 位小数，默认 2 位。

## 日期与假期

```text
日期与假期

所在地区             [ 中国大陆       ▾ ]
语言                 [ 跟随系统       ▾ ]

发薪规则             [ 每月固定日     ▾ ]
发薪日期             [ 每月 15 日     ▾ ]
遇休息日             (•) 顺延  ( ) 提前  ( ) 不调整

自定义假期           [ 管理假期… ]
日期覆盖             [ 管理工作日/休息日… ]
节假日数据           已安装 / 检查更新
```

- 首批地区： 中国大陆、美国、日本、韩国、中国香港、中国台湾。
- 发薪规则：每月固定日、每月最后工作日、每月两次。选择不同规则时，仅展示对应字段。
- 固定日期支持 1–31 号；超过当月天数时按冻结规则处理。
- 遇休息日规则：顺延、提前、不调整。
- 自定义假期支持名称、起止日期及类型；一期原型仅呈现已冻结范围。
- 数据缺失时按每周工作日降级，并显示数据状态提示。

## 悬浮窗与显示（桌面端）

```text
悬浮窗与显示

启动时形态           (•) 迷你  ( ) 标准  ( ) 展开
迷你态显示内容                         [添加自定义倒计时]
  ☑ 距离下班         拖动排序
  ☑ 今日已赚         拖动排序
  ☑ 距离放假         拖动排序
  ☑ 生命倒计时       拖动排序
  ☑ 退休倒计时       拖动排序

标准/展开显示内容
  ☑ 上下班状态       拖动排序
  ☑ 今日已赚
  ☑ 本月已赚
  ☑ 发薪日
  ☑ 下次放假
  ☑ 退休
  ☑ 生命

显示主题             ( ) 浅色  ( ) 深色  (•) 跟随系统
强调色               [ 色板 ]
透明度               [────────●──] 30%–100%
字号                 ( ) 小  (•) 中  ( ) 大

☑ 窗口置顶            ☑ 靠近边缘时吸附
☐ 在全屏应用上方显示  ☐ 开机启动
双击悬浮窗           迷你 / 标准切换
```

- 首次启动及默认启动形态为迷你；默认显示距离下班、今日已赚、距离放假、生命倒计时和退休倒计时。各项可独立关闭、排序，也可全部显示。
- 标准态与展开态的指标可单独显示/隐藏并调整顺序；默认顺序如上。
- 自定义倒计时可输入名称、目标日期和时间，保存后加入显示列表，可关闭、排序、编辑或删除；该功能不在当前冻结清单中，需确认是否纳入一期。
- 隐藏金额可通过桌面菜单/快捷键切换；敏感金额显示为 `****`，支持临时查看。
- 拖动、吸边、位置记忆、多显示器与锁定/点击穿透属于悬浮窗操作，不在此页模拟成设置项以外的新功能。
- 快捷键入口放在通用设置中。

## 小组件（移动端）

```text
小组件

倒计时小组件
  可用内容：距离下班 / 距离放假 / 距离发薪 / 距离退休
  更新方式：系统计时器走秒

薪资小组件
  可用内容：今日已赚 / 本月已赚
  更新方式：约每分钟更新
  更新时间标记：约 X 分钟前更新

[查看添加方式]
```

- 小组件具体添加流程由 iOS / Android 系统承载。
- 不承诺薪资逐秒刷新；需显示最近更新时间。

## 通用

```text
通用

语言                 [ 跟随系统       ▾ ]
显示/隐藏快捷键       [ Ctrl/Cmd + Shift + T ]
隐藏金额快捷键       [ 设置快捷键… ]
暂停计时显示         [ 开关：关 ]

导入设置             [ 导入 JSON… ]
导出设置             [ 导出 JSON… ]
检查节假日数据       [ 立即检查 ]
关于                 [ 版本与许可… ]
退出应用             [ 退出 ]
```

- 支持语言：简体中文、English、繁體中文、日本語、한국어、Español、Deutsch、Français。
- 设置导入/导出为本地 JSON 文件。
- 不包含通知、自动更新、带薪/无薪假标记等未纳入一期的功能入口。

## 首次启动引导

```text
1. 个人信息  →  2. 作息与薪资  →  3. 悬浮窗预览
```

- 第 1 步填写出生日期、预期寿命和退休日期。
- 第 2 步填写工作时间、工作日、月薪、币种和发薪规则。
- 第 3 步预览迷你悬浮窗，默认显示“距离下班”；完成后进入桌面常驻迷你态。
- 可跳过非必填项；未设置的数据对应指标显示“未设置”，点击可进入相应设置。
