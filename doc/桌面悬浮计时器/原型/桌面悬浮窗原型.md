# 桌面悬浮窗原型

版本：v0.1（讨论稿）  
适用：Windows 10+、macOS 12+  
依据：`../最终确认-可以开始开发.md`；迷你态内容依据后续讨论补充。

## 形态与默认行为

- 首次启动及默认启动形态：迷你。
- 迷你态支持多项指标同时显示；用户可逐项开启/关闭、排序，也可全部显示。
- 默认迷你态显示：距离下班、今日已赚、距离放假、生命倒计时、退休倒计时；自定义倒计时由用户添加后显示。
- 双击悬浮窗：迷你态与标准态切换。
- 标准态与展开态内容由用户勾选、排序；皮肤与三种形态由冻结功能支持。
- 默认置顶；窗口无边框、透明背景，可拖拽、吸边、记忆位置；默认不遮挡全屏应用。

## 迷你态

```text
┌──────────────────────────────────┐
│ 下班       02:14:33               │
│ 今日已赚   ¥375.42  计薪中        │
│ 放假       23天 04:12:08          │
│ 生命       25,412天 08:16:40      │
│ 退休       8,204天 03:22:10       │
│ 产品上线   120天 06:15:42         │
└──────────────────────────────────┘
```

- 各指标可独立开启/关闭、调整顺序，也可全部显示；默认显示下班、今日已赚、放假、生命和退休倒计时。
- 今日已赚在有效工作时段逐秒上涨，显示“计薪中”；午休、下班后或休息日显示“暂停计薪”，金额依据计算规则而非界面累加。
- 计时值使用等宽数字并按系统时间重算；状态变化时更新文案，例如“午休结束 00:24:10”“距离上班 01:05:00”。
- 生命、退休和自定义倒计时按秒展示剩余时间。窗口空间不足时允许增高或滚动，不静默隐藏已开启项目。
- 自定义倒计时由用户填写名称、目标日期和时间；到达目标后显示“已到期”，不显示负数。此项不在现有冻结清单中，需另行确认一期范围。
- 金额隐藏时显示 `****`；点击眼睛图标临时查看。

## 迷你态指标管理

```text
迷你态显示内容                         [添加自定义倒计时]
☑ 距离下班                       ≡
☑ 今日已赚                       ≡
☑ 距离放假                       ≡
☑ 生命倒计时                     ≡
☑ 退休倒计时                     ≡
☑ 产品上线 · 2027-03-01 09:00     ≡
```

- 复选框控制显示状态；拖动排序控制浮窗顺序。
- 自定义倒计时字段：名称、目标日期、目标时间；名称必填，目标需晚于当前时间。
- 支持编辑和删除自定义倒计时；删除前确认。

## 标准态

```text
┌───────────────────────────────┐
│  桌面悬浮计时器             ⋯ │
│                               │
│  距离下班                 02:14:33
│  今日已赚              ¥375.00
│  本月已赚             ¥8,420.00
│  距离发薪                 11天
│  下次放假                 23天
│  距离退休               8,204天
│  生命剩余          2,451,203 秒
└───────────────────────────────┘
```

- 默认信息顺序：上下班、今日已赚、本月已赚、发薪日、放假、退休、生命。
- 用户可以在设置中单独显示/隐藏和调整顺序；实际窗口高度随内容变化。
- 头部菜单提供形态切换与设置入口；拖动卡片空白处移动窗口。
- 标准态展示完整可配置指标；与迷你态共用指标开关和排序，并可补充次要信息。

## 展开态

```text
┌──────────────────────────────────┐
│  桌面悬浮计时器                ⋯ │
│                                  │
│  距离下班                         │
│  02:14:33                         │
│  今日工作进度  ███████░░░  71%    │
│                                  │
│  今日已赚     ¥375.00             │
│  本月已赚   ¥8,420.00             │
│  发薪日       11天 04:22:18       │
│  下次放假     23天 01:18:10       │
│  退休         8,204天             │
│  生命         2,451,203 秒        │
└──────────────────────────────────┘
```

- 在标准态上增加进度条及次要信息；进度条可选显示。
- 数值和说明由核心计算快照提供，不因切换形态改变。
- 保持透明度、字号、主题和强调色设置；宽度与高度遵循皮肤布局模板。

## 交互与状态

- 拖动：卡片任意空白区域拖动；按显示器保存位置。拔除原显示器后回到主屏右上角。
- 吸边：距屏幕边缘 12px 内吸附；可在设置中关闭。
- 锁定：从托盘/菜单栏切换锁定后启用点击穿透；由系统菜单取消锁定。
- 隐藏：托盘/菜单栏、全局快捷键均可显示/隐藏；隐藏或锁屏时暂停界面刷新，恢复后立即重算。
- 全屏：默认不覆盖全屏应用；可在设置启用全屏上方显示。
- 金额隐私：全局隐藏金额开关，显示为 `****`；点击眼睛图标临时查看。
- 暂停：暂停计时显示仅冻结界面更新，不修改计算基准；恢复时按当前系统时间重算。

## 视觉规范

- 两套内置皮肤：简约卡片、深色科技。
- 主题浅色/深色/跟随系统；透明度 30%–100%；字号小/中/大；强调色可选。
- 数字使用等宽数字。状态标签和单位需完整，不能仅用颜色表达状态。
- 低干扰呈现，避免大面积遮挡桌面内容；窗口保持足够尺寸以满足可读性和点击区域。

## 待原型确认

- 标准态默认可见指标是否全部开启，或提供更紧凑的默认组合。
- 标准态标题栏是否常驻显示，还是仅悬停时显示操作入口。
- 多项同时显示时，迷你窗的最大高度、滚动方式与最小尺寸。
- 自定义倒计时是否正式加入一期冻结范围。
- 展开态工作进度条默认开或关。
