# 项目基础信息

## 项目名称

- 中文工作名：**时余**
- 英文工作名：**Time Remaining**（描述性译名，非最终品牌名）
- 原项目名称：桌面悬浮计时器
- 命名说明：“时”代表工作、假期与人生时间；“余”代表倒计时中的剩余，也呼应工作时间所创造的收入。名称简短，不把产品限制在桌面端。

## 项目概况

| 项目 | 内容 |
| --- | --- |
| 产品定位 | 低干扰的时间与薪资感知工具，以桌面悬浮窗为核心，提供移动端应用和手机小组件 |
| MVP 版本 | 1.0 |
| 当前状态 | 需求冻结，进入开发准备 |
| MVP 冻结日期 | 2026-11-04 |
| 目标用户 | 希望快速查看工作时间、收入、假期及个人长期倒计时的上班族 |
| 核心价值 | 用同一套准确、可解释的本地计算，在桌面和移动端呈现与工作和生活相关的时间信息 |
| 数据原则 | 默认本地保存；薪资及个人信息不上传；网络仅用于节假日数据获取 |
| 团队假设 | 2 人开发团队；Rust、Flutter 及原生平台构建能力按排期文档假设 |

## 平台与技术

### 平台范围

- 桌面：Windows 10+、macOS 12+。
- 移动端：iOS、Android。
- 桌面系统入口：Windows 系统托盘、macOS 菜单栏。
- 手机小组件：iOS WidgetKit/SwiftUI；Android Glance 或 RemoteViews。

### 技术基线

- 业务计算：Rust，jiff 时区处理、rust_decimal 金额精度。
- 桌面与移动 UI：Flutter、Riverpod、ARB 国际化。
- Flutter 调用 Rust：flutter_rust_bridge。
- 原生 Widget 调用 Rust：UniFFI。
- 本地设置：版本化 JSON；iOS App Group、Android 应用共享存储用于小组件数据交换。
- 节假日：安装包内置数据、联网检查更新、离线缓存与降级计算。
- 桌面窗口：Flutter 桌面窗口管理插件为基础，平台特性以原生桥接补齐。

## MVP 核心范围

- 六类内置信息：生命倒计时、上下班状态、今日/本月薪资、发薪日、下次放假、退休倒计时。
- 桌面默认以迷你悬浮窗启动；默认显示下班、今日已赚、放假、生命、退休五项，可逐项开关、排序，也可全部显示。
- 桌面迷你态支持用户创建自定义倒计时：名称、目标日期和时间，按秒显示；此功能不进入 1.0 手机小组件。
- 桌面支持迷你/标准/展开三态、托盘/菜单栏、拖动、吸边、点击穿透、多显示器、皮肤与资源包。
- 移动端提供全屏应用与倒计时/薪资两类小组件；薪资小组件约每分钟更新并显示最近更新时间。
- 首批支持 6 个地区、8 种语言，详见 MVP 冻结需求。

## 明确不纳入 MVP

通知、云同步、账号、年薪/时薪输入、大小周、跨零点夜班、每周/双周发薪、带薪/无薪假、自动更新、托盘长按预览、菜单栏文字，以及手机端自定义倒计时管理与组件展示。

## 项目成功标准

- 计时、日历、薪资与倒计时计算由 Rust 单一实现，桌面、移动端和 Widget 使用统一计算契约。
- 桌面核心信息易扫读、干扰低；窗口行为在 Windows/macOS 上满足冻结要求。
- 手机全屏应用和小组件可独立读取本地共享设置；薪资 Widget 清楚标明更新时间。
- 薪资和个人数据不出设备；节假日数据缺失或断网时可用并按规则降级。
- 通过《MVP 冻结需求 1.0》验收标准及《最终开发步骤、排期与测试验证》发布门槛。
