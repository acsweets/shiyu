# 桌面悬浮计时器 MVP 冻结需求 1.0

版本：1.0  
冻结日期：2026-11-04  
状态：MVP 范围冻结，作为一期设计、开发与验收基线  
产品：桌面悬浮计时器  
平台：Windows 10+、macOS 12+、iOS、Android

## 1. 文档目的与优先级

本文件汇总当前讨论形成的 MVP 冻结需求。若本文件与旧版 PRD、决策草稿或原型稿冲突，以本文件为准。原型用于呈现本文件，不得自行扩展产品行为；变更冻结需求需记录新版本及变更原因。

本次明确纳入 MVP 的原型决策：

- 桌面应用默认以迷你悬浮窗启动。
- 迷你悬浮窗默认展示距离下班、今日已赚、距离放假、生命倒计时、退休倒计时；用户可以逐项开关、排序，也可以全部显示。
- 迷你悬浮窗允许用户新增自定义倒计时，填写名称、目标日期和时间，并按秒展示剩余时间。

自定义倒计时此前不在《最终确认-可以开始开发.md》的冻结清单中；本 1.0 将其正式纳入 MVP，但范围限定为桌面悬浮窗/桌面设置。移动端通用自定义倒计时及手机小组件显示自定义项目不属于 1.0。

## 2. 产品目标

提供低干扰、常驻桌面的时间与薪资悬浮窗，并提供配套移动端应用和手机小组件。用户一眼查看工作、收入、假期、退休和生命倒计时；计算准确、跨平台一致，个人设置和薪资数据默认保存在本地。

## 3. 平台与一期范围

### 3.1 桌面

- Windows 10 及以上、macOS 12 及以上。
- Flutter 桌面应用，Rust 计算核心。
- 无边框透明悬浮窗，迷你、标准、展开三种形态。
- Windows 系统托盘、macOS 菜单栏入口。

### 3.2 移动端

- iOS、Android Flutter 全屏应用。
- iOS WidgetKit/SwiftUI 小组件；Android Glance 或 RemoteViews 小组件。
- 移动端复用 Rust 计算核心；原生小组件通过 FFI 调用核心并读取共享设置。

### 3.3 地区与语言

首批地区：中国大陆、美国、日本、韩国、中国香港、中国台湾。首批语言：简体中文、English、繁體中文、日本語、한국어、Español、Deutsch、Français。

## 4. 核心功能需求

### F-01 生命倒计时

- 出生日期必填；出生时刻可选，默认 00:00。
- 预期寿命默认 100 年，支持一位小数，范围 1–150 年。
- 目标时刻按出生时刻加预期寿命的日历年计算；2 月 29 日在非闰年按 2 月 28 日处理。
- 每秒刷新，显示剩余时间；展示格式至少支持剩余秒数及年/天/时/分/秒格式。
- 超过目标时刻显示“已超出预期，请调整设定”，不显示负数。

### F-02 工作状态与上下班倒计时

- 设置上班、下班、午休开始和结束时间；午休可关闭。
- 下班时间必须晚于上班时间，不支持跨零点夜班。
- 工作日由地区默认值及每周七日复选框确定；固定工作日制度，不支持大小周。
- 显示状态：休息日距离下个工作日上班、未上班距离上班、工作中距离下班、午休中距离午休结束、已下班距离下次工作日上班。
- 休息日、调休补班和节假日依据地区日历及用户日期覆盖计算。

### F-03 实时薪资

- 输入税前月薪（必填）、税后月薪（选填）；不支持年薪或时薪输入。
- 用户选择税前或税后显示口径；未填税后薪资时税后选项不可选。
- 币种默认由地区提供；精度支持 2–4 位小数，默认 2 位。
- 展示今日已赚、本月已赚；可提供自动计算的时薪信息。
- 薪资仅在有效工作时段增长；午休、下班后及休息日不增长。
- 每月按当月应出勤天数计算每秒薪资；不得用二进制浮点累加。金额使用十进制精度并向下截断显示。
- 可全局隐藏金额；隐藏状态显示 `****`，可通过受控的临时查看入口查看。
- 修改月薪或作息后按新设置重算当日金额，不保留旧设置计算值。

### F-04 发薪日倒计时

- 支持每月固定日、每月最后工作日、每月两次三种发薪规则。
- 固定日期为 1–31 号；超过当月天数时取当月最后一天。
- 遇休息日可选择顺延、提前或不调整；默认顺延到下一个工作日。
- 显示目标日期倒计时；发薪日当天显示“今天发薪”，过后切换到下一次发薪日。

### F-05 下次放假倒计时

- 节假日数据与用户自定义假期共同构成休息日；支持“每周休息日算放假”开关，默认开启。
- 连续休息日合并为同一假期区间。
- 非休息期间，倒计时目标为连续休息开始前最后一个工作日下班时刻。
- 当前处于休息期间时显示放假中、距离结束时间及下一段休息信息。

### F-06 退休倒计时

- 用户直接填写退休日期，不自动推算。
- 显示剩余天数，并支持年/月/天或天/时/分/秒表达。
- 日期已到或已过时显示“已退休”，不显示负数。

### F-07 自定义倒计时（本版新增冻结项）

- 桌面端用户可以创建多个自定义倒计时。
- 每项包含名称、目标日期、目标时间；名称和目标日期时间必填。
- 新建时目标必须晚于当前时间；允许编辑、删除及在迷你浮窗显示列表中开关和排序。
- 按秒显示剩余时间；到达目标时显示“已到期”，不显示负数。
- 配置保存在本地。
- 1.0 不要求移动端全屏页或手机小组件展示、管理自定义倒计时。

## 5. 桌面悬浮窗

### 5.1 窗口形态和默认值

- 迷你、标准、展开三种形态；默认启动形态为迷你。
- 双击在迷你与标准间切换；展开态可由窗口菜单或设置进入。
- 迷你态默认指标：距离下班、今日已赚、距离放假、生命倒计时、退休倒计时。用户创建的自定义倒计时可加入显示列表。
- 迷你态每项可独立开关、排序；允许全部开启。窗口不得静默隐藏已开启项目；内容溢出时按布局增高或滚动。
- 标准态展示用户选择的多个指标，默认顺序：上下班、今日已赚、本月已赚、发薪日、放假、退休、生命；自定义倒计时可加入。
- 展开态在标准态基础上显示进度条和次要信息。

### 5.2 窗口行为

- 无边框、背景透明、默认置顶，默认不显示任务栏/Dock 图标。
- 可拖动；按显示器保存位置；原显示器不可用时回到主屏右上角。
- 靠近屏幕边缘 12px 自动吸附，可关闭。
- 支持锁定/点击穿透；从托盘或菜单栏解除锁定。
- 支持多显示器和跨 DPI 缩放。
- 默认不覆盖全屏应用；提供“在全屏应用上方显示”选项，macOS 支持覆盖全屏 Space。
- 全局快捷键显示/隐藏，默认 Ctrl/Cmd + Shift + T；另设隐藏金额快捷键，均可自定义。
- 单实例；可选开机自启，默认关闭。

### 5.3 外观

- 两套内置皮肤：简约卡片、深色科技。
- 支持皮肤导入、导出、双击安装 `.timerpack`、单个素材替换。
- L1 设计令牌与 L2 布局模板；不执行第三方脚本或代码。
- 主题浅色/深色/跟随系统，透明度 30%–100%，字号三档，强调色可选。
- 数字使用等宽数字；跨平台布局与数据表达保持一致。

## 6. 设置与首次启动

- 设置修改后立即生效并自动保存；非法输入就地提示，保留上次合法值。
- 设置分组：个人信息、作息与薪资、日期与假期、悬浮窗外观、通用；移动端隐藏桌面专属窗口行为项，并提供小组件设置说明。
- 首次启动引导三步：个人信息 → 作息与薪资 → 悬浮窗/首页预览。
- 支持本地 JSON 设置导入与导出。
- 桌面设置提供迷你态指标开关、排序、自定义倒计时管理。
- 本地保存，无账号体系、无云同步。

## 7. 托盘与菜单栏

- Windows 使用系统托盘；macOS 使用菜单栏图标。
- 菜单包含：显示/隐藏悬浮窗、隐藏金额、打开设置、暂停计时显示、检查节假日数据更新、退出。
- 锁定/解除悬浮窗点击穿透可从系统入口操作。
- 暂停只暂停界面显示更新；恢复后按当前系统时间重算。
- 不包含菜单栏文字显示与长按预览。

## 8. 移动端应用与小组件

### 8.1 移动应用

- 提供六大核心计时数据及薪资信息的全屏响应式界面。
- 设置和业务字段与桌面共享；桌面窗口置顶、吸边、多显示器、点击穿透、桌面快捷键等不显示。
- 移动端调用同一 Rust 核心，避免与桌面计算结果不一致。

### 8.2 倒计时小组件

- 内容：距离下班、距离放假、距离发薪、距离退休。
- 根据系统能力通过时间线/计时器走秒显示。
- 支持平台可用的紧凑与宽尺寸；不足以显示多指标时展示用户选择的主指标。

### 8.3 薪资小组件

- 内容：今日已赚、本月已赚。
- 以约每分钟为目标请求更新，卡面显示薪资指标和数值。
- 使用共享设置和同一 Rust 核心独立计算；主应用未运行时仍可显示。
- 同步隐藏金额状态；金额不可见时显示 `****`。

### 8.4 小组件边界

- iOS 使用 App Group 共享数据；Android 使用应用共享存储。
- 小组件读取设置与节假日数据并自行计算。平台后台刷新策略可能影响刷新时点，刷新状态由系统调度。
- 小组件不包含自定义倒计时（MVP 1.0）。

## 9. 节假日与数据

- 首批支持六个地区；安装包内置当年和次年数据，启动后联网检查更新，失败静默使用本地缓存；支持手动检查与手动导入数据。
- 数据更新请求仅下载节假日数据，不携带个人设置或薪资。
- 数据缺失时按周工作日设置降级计算，并在应用界面提示。
- 用户可将任意日期覆盖为工作日或休息日，覆盖优先级最高。
- 自定义假期支持名称、开始日期、结束日期和类型；不包含带薪/无薪假标记（后续版本）。

## 10. 隐私与本地存储

- 无账号、无埋点、无云同步。
- 个人信息、薪资、显示偏好和自定义倒计时保存在本地应用数据目录。
- 薪资不上传、不写入日志；1.0 配置文件不加密，文件权限限当前用户。
- 网络仅用于节假日数据获取和更新。

## 11. 明确不做

- 通知功能。
- 带薪假/无薪假标记。
- 托盘/菜单栏长按预览、菜单栏文字显示。
- 自动更新。
- 年薪输入、时薪输入。
- 大小周轮换、跨零点夜班、每周/每两周发薪、农历/非公历。
- 账号体系、云同步、上传用户设置。
- 手机端自定义倒计时管理与自定义倒计时小组件。

## 12. 性能与质量目标

| 指标 | 桌面 | 移动 |
| --- | --- | --- |
| 内存 | <120 MB | <80 MB |
| 平均 CPU | <1% | <2% |
| 冷启动 | <2 秒 | <1.5 秒 |
| 核心 compute 延迟 | <1 ms | <1 ms |

- 计时误差不超过 1 秒；每次刷新从当前系统时间重算，不使用累加器作为时间真值。
- 窗口隐藏或锁屏时暂停界面刷新；唤醒/显示后立即重算。
- 监听休眠唤醒、系统时间修改、时区变化和日期跨日。
- 桌面连续运行 7 天无明显内存增长；设置在异常退出后恢复。
- 支持 Windows 125%、150%、200% 缩放及 macOS Intel/Apple Silicon。

## 13. MVP 验收标准

1. 首次启动桌面默认进入迷你态，默认出现下班、今日已赚、放假、生命和退休五项。
2. 用户可单独关闭任意迷你指标、恢复开启、排序，并开启全部指标；关闭后重启保留选择。
3. 用户创建自定义倒计时，输入名称与未来日期时间；其剩余时间按秒变化，编辑/删除后状态正确，重启后数据保留。
4. 自定义目标到达后显示“已到期”，不出现负数。
5. 有效工作时段内今日已赚逐秒增长；午休、下班后和休息日不增长；隐藏金额后所有对应界面遮蔽金额。
6. 标准/展开态展示所选指标；迷你、标准、展开切换不改变计算值。
7. 拖动、吸边、锁定穿透、多显示器位置恢复和显示/隐藏快捷键符合定义。
8. 发薪规则三种方式及提前/顺延/不调整规则计算正确。
9. 放假区间能够合并周末与连续法定假期；缺失节假日数据时按工作日设置降级并提示。
10. Windows 与 macOS 使用同一配置时核心指标结果一致。
11. iOS/Android 应用可查看和配置核心数据。倒计时小组件显示四类冻结指标，薪资小组件按约每分钟的策略请求更新。
12. 网络关闭时应用可用本地节假日数据正常运行；无任何用户设置或薪资网络请求。
13. 达到第 12 节性能目标；计时恢复不依赖进程运行期间的累加状态。
