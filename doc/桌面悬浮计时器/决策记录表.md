| 时薪支持 | P1 | P1 | 保持不变 |
| 每两周发薪 | P1 | P1 | 保持不变 |

| 功能 | 理由 |

## 七、建议决策流程

### 第一轮（启动前必须确认，1-2天）

**高优先级决策** - 影响技术方案和M0验证:

1. **D-R-01**: 团队Rust经验评估
2. **D-T-12**: 是否接受不上架Mac App Store
3. **D-T-08**: 节假日数据v1方案（内置打包）
4. **D-P-13**: v1首批语言确认
5. **D-P-15**: v1首批地区确认
6. **D-M-06**: M0是否验证最小小组件
7. **D-R-03**: 开发者证书准备

### 第二轮（M0阶段确认，1周内）

**M0验证后确认** - 基于原型验证结果:

1. **D-T-06**: 时区库选择（jiff vs chrono-tz）
2. **D-T-10**: 节假日数据源评估
3. **D-T-13**: macOS全屏上方显示可行性
4. **D-T-25**: 内存指标（基于实测）
5. **D-T-28~D-T-30**: 性能指标（基于实测）

### 第三轮（M1开始前确认，随时可调整）

**中低优先级决策** - 不阻塞主流程:

1. 所有P1功能的优先级确认
2. 资源包扩展名等命名决策
3. 第二批语言与地区的具体范围
