## 1. 技术选型概述

### 1.1 选型原则

1. **分离关注点**: 计算逻辑与UI完全解耦
2. **一次编写，多端复用**: 核心业务逻辑供桌面和未来手机端共用
3. **性能优先**: 常驻应用，低内存低CPU占用
4. **跨平台一致性**: Windows和macOS行为一致
5. **可维护性**: 清晰的模块边界和测试覆盖

### 1.2 技术栈决策

| 层级 | 技术选择 | 理由 |
|------|---------|------|
| **核心计算层** | Rust | 高性能、内存安全、跨平台、适合复杂计算逻辑 |
| **桌面UI层** | Flutter Desktop | 自绘渲染保证跨平台一致性、丰富的UI组件、热重载提升开发效率 |
| **桌面端绑定** | flutter_rust_bridge | 成熟的Rust-Dart绑定方案、自动生成绑定代码 |
| **移动端绑定** | UniFFI (Mozilla) | Rust到Swift/Kotlin的标准绑定方案（后续阶段） |
| **窗口管理** | window_manager | Flutter插件，支持透明、置顶、拖拽等 |
| **系统托盘** | tray_manager | 跨平台托盘/菜单栏管理 |
| **状态管理** | Riverpod | 现代化的Flutter状态管理，支持代码生成 |
| **本地存储** | JSON + path_provider | 简单直接，易于调试和迁移 |

### 1.3 架构对比

我们对比了以下方案：

#### 方案A: Tauri 2 (未选择)
- **优势**: 包体更小(5-10MB)，内存占用更低(30-60MB)
- **劣势**: 
  - macOS透明窗口需要私有API，影响上架
  - 移动端支持较新，生态不够成熟
  - 悬浮窗细节控制不如专业框架

#### 方案B: Electron (未选择)
- **优势**: 桌面生态最成熟，文档丰富
- **劣势**: 
  - 包体巨大(80-150MB)，内存占用高(100-200MB)
  - 不适合常驻应用
  - 无法复用到移动端

#### 方案C: Flutter + Rust (已选择) ✅
- **优势**: 
  - 跨平台UI一致性最好
  - 核心库可复用到移动端（包括原生小组件）
  - 性能适中，内存可控(80-120MB)
  - 团队技术栈匹配（假设有Flutter经验）
- **劣势**: 
  - 需要学习Rust（可控风险）
  - 构建配置较复杂

### 2.2 模块职责划分

#### 2.2.1 Rust核心库 (core/)

**职责**: 
- 纯计算逻辑，无副作用
- 日历运算（工作日判定、应出勤天数、下次放假）
- 薪资计算（每秒薪资、今日已赚、本月已赚）
- 倒计时计算（生命、下班、发薪、退休）
- 时区与夏令时处理

**不负责**:
- 系统时间读取（由宿主传入）
- 网络请求
- 文件读写
- UI渲染

#### 2.2.2 Flutter应用层 (app/)

**职责**:
- UI渲染与交互
- 窗口管理（透明、置顶、拖拽、穿透）
- 系统托盘/菜单栏
- 设置存储与读取
- 节假日数据下载与缓存
- 定时器触发（每秒调用Rust核心）
- 皮肤系统加载与渲染

```rust
// compute.rs

use crate::types::*;
use std::result::Result;

/// 统一计算入口
/// 
/// # 参数
/// - settings: 用户设置
/// - holidays: 节假日数据
/// - now_utc_millis: 当前UTC时间戳（毫秒）
/// - time_zone_id: IANA时区ID（如"Asia/Shanghai"）
///
/// # 返回
/// - Ok(Snapshot): 当前时刻的完整快照
/// - Err(ComputeError): 计算错误
pub fn compute(
    settings: &Settings,
    holidays: &HolidayData,
    now_utc_millis: i64,
    time_zone_id: &str,
) -> Result<Snapshot, ComputeError> {
    // 1. 时区转换
    let now_local = convert_to_local(now_utc_millis, time_zone_id)?;
    
    // 2. 工作日判定
    let today_type = calendar::determine_day_type(
        now_local.date(),
        &settings.work_days,
        holidays,
        &settings.day_overrides,
    );
    
    // 3. 工作状态
    let work_state = countdown::compute_work_state(
        now_local.time(),
        today_type,
        settings,
    );
    
    // 4. 薪资计算
    let salary_snapshot = salary::compute_salary(
        now_local,
        settings,
        holidays,
        &settings.day_overrides,
    )?;
    
    // 5. 发薪日
    let next_pay_date = calendar::compute_next_payday(
        now_local.date(),
        &settings.pay_rule,
        holidays,
    )?;
    
    // 6. 下次放假
    let next_holiday = calendar::compute_next_holiday(
        now_local,
        settings,
        holidays,
    );
    
    // 7. 退休与生命倒计时
    let retire_remaining = countdown::compute_retire_countdown(
        now_local,
        settings.retire_date,
    );
    
    let life_remaining = countdown::compute_life_countdown(
        now_local,
        settings.birth_date_time,
        settings.life_expectancy_years,
    );
    
    // 8. 组装快照
    Ok(Snapshot {
        timestamp: now_local,
        work_state,
        next_state_change: compute_next_state_change(&work_state),
        per_second_salary: salary_snapshot.per_second,
        today_earned: salary_snapshot.today,
        today_earned_display: format_money(
            salary_snapshot.today, 
            settings.money_precision
        ),
        month_earned: salary_snapshot.month,
        month_earned_display: format_money(
            salary_snapshot.month, 
            settings.money_precision
        ),
        next_pay_date,
        pay_countdown_seconds: compute_countdown_seconds(now_local, next_pay_date),
        next_holiday,
        holiday_countdown_seconds: next_holiday.as_ref()
            .map(|h| compute_countdown_seconds(now_local, h.start_time)),
        retire_remaining_days: retire_remaining.days,
        retire_remaining_seconds: retire_remaining.seconds,
        life_remaining_seconds: life_remaining,
        next_change_at: compute_next_refresh_time(&work_state, now_local),
        calculation_warnings: vec![],
    })
}

/// 生成时间线（供小组件使用）
///
/// # 参数
/// - settings: 用户设置
/// - holidays: 节假日数据
/// - start_utc_millis: 起始时间
/// - step_seconds: 步长（秒）
/// - count: 生成数量
pub fn timeline(
    settings: &Settings,
    holidays: &HolidayData,
    start_utc_millis: i64,
    step_seconds: i64,
    count: usize,
) -> Result<Vec<Snapshot>, ComputeError> {
    let mut snapshots = Vec::with_capacity(count);
    let mut current_millis = start_utc_millis;
    
    for _ in 0..count {
        let snapshot = compute(
            settings,
            holidays,
            current_millis,
            &settings.time_zone_id.clone().unwrap_or_default(),
        )?;
        snapshots.push(snapshot);
        current_millis += step_seconds * 1000;
    }
    
    Ok(snapshots)
}

/// 校验设置
pub fn validate_settings(settings: &Settings) -> Vec<ValidationError> {
    let mut errors = Vec::new();
    
    // 作息时间校验
    if settings.work_end <= settings.work_start {
        errors.push(ValidationError::InvalidWorkTime(
            "下班时间必须晚于上班时间".into()
        ));
    }
    
    // 午休时间校验
    if let (Some(lunch_start), Some(lunch_end)) = 
        (settings.lunch_start, settings.lunch_end) {
        if lunch_start < settings.work_start || lunch_end > settings.work_end {
            errors.push(ValidationError::InvalidLunchTime(
                "午休时间必须在工作时间内".into()
            ));
        }
    }
    
    // 薪资校验
    if settings.gross_monthly_salary <= Decimal::ZERO {
        errors.push(ValidationError::InvalidSalary(
            "月薪必须大于0".into()
        ));
    }
    
    // 更多校验...
    
    errors
}
```

### 3.4 关键算法实现

#### 3.4.1 薪资计算

```rust
// salary/calculator.rs

pub fn compute_salary(
    now: LocalDateTime,
    settings: &Settings,
    holidays: &HolidayData,
    overrides: &HashMap<Date, DayType>,
) -> Result<SalarySnapshot, ComputeError> {
    // 1. 计算当月应出勤天数
    let work_days_in_month = count_work_days_in_month(
        now.date().year(),
        now.date().month(),
        &settings.work_days,
        holidays,
        overrides,
    );
    
    if work_days_in_month == 0 {
        return Ok(SalarySnapshot::zero());
    }
    
    // 2. 计算每日有效工作秒数
    let daily_work_seconds = compute_daily_work_seconds(settings);
    
    // 3. 计算每秒薪资 = 月薪 / 应出勤天数 / 每日工作秒数
    let monthly_salary = match settings.salary_basis {
        SalaryBasis::Gross => settings.gross_monthly_salary,
        SalaryBasis::Net => settings.net_monthly_salary
            .ok_or(ComputeError::MissingNetSalary)?,
    };
    
    let per_second_salary = monthly_salary 
        / Decimal::from(work_days_in_month)
        / Decimal::from(daily_work_seconds);
    
    // 4. 计算今日已工作秒数
    let today_worked_seconds = compute_today_worked_seconds(
        now.time(),
        settings,
    );
    
    // 5. 今日已赚 = 每秒薪资 × 今日已工作秒数
    let today_earned = per_second_salary 
        * Decimal::from(today_worked_seconds);
    
    // 6. 本月已赚 = 已完成工作日日薪总和 + 今日已赚
    let month_earned = compute_month_accumulated(
        now.date(),
        per_second_salary,
        daily_work_seconds,
        settings,
        holidays,
        overrides,
    ) + today_earned;
    
    Ok(SalarySnapshot {
        per_second: per_second_salary,
        today: today_earned,
        month: month_earned,
    })
}

/// 计算今日已工作秒数（扣除午休）
fn compute_today_worked_seconds(
    current_time: Time,
    settings: &Settings,
) -> u64 {
    let work_start = settings.work_start;
    let work_end = settings.work_end;
    
    // 未上班
    if current_time < work_start {
        return 0;
    }
    
    // 已下班
    if current_time >= work_end {
        // 返回全天工作秒数
        return compute_daily_work_seconds(settings);
    }
    
    // 上班中
    let mut worked = (current_time - work_start).whole_seconds() as u64;
    
    // 扣除午休
    if let (Some(lunch_start), Some(lunch_end)) = 
        (settings.lunch_start, settings.lunch_end) {
        if current_time > lunch_start {
            let lunch_duration = (lunch_end - lunch_start).whole_seconds() as u64;
            if current_time >= lunch_end {
                // 午休已结束，扣除全部午休时间
                worked -= lunch_duration;
            } else {
                // 午休中，扣除到当前时刻的午休时间
                worked -= (current_time - lunch_start).whole_seconds() as u64;
            }
        }
    }
    
    worked
}
```

```dart
// state/providers/snapshot_provider.dart

import 'package:riverpod_annotation/riverpod_annotation.dart';
import '../../core/rust_api.dart';
import '../../core/models/snapshot.dart';

part 'snapshot_provider.g.dart';

/// 当前快照Provider
@riverpod
class CurrentSnapshot extends _$CurrentSnapshot {
  Timer? _timer;
  
  @override
  Future<Snapshot> build() async {
    // 监听设置变化
    ref.listen(settingsProvider, (_, __) {
      _recompute();
    });
    
    // 启动定时器
    _startTimer();
    
    // 初始计算
    return _compute();
  }
  
  void _startTimer() {
    _timer?.cancel();
    
    // 对齐到整秒
    final now = DateTime.now();
    final nextSecond = DateTime(
      now.year, now.month, now.day,
      now.hour, now.minute, now.second + 1,
    );
    final delay = nextSecond.difference(now);
    
    Future.delayed(delay, () {
      _timer = Timer.periodic(
        const Duration(seconds: 1),
        (_) => _recompute(),
      );
    });
  }
  
  Future<void> _recompute() async {
    state = AsyncValue.data(await _compute());
  }
  
  Future<Snapshot> _compute() async {
    final settings = ref.read(settingsProvider);
    final holidays = await ref.read(holidayDataProvider.future);
    
    final nowUtcMillis = DateTime.now().toUtc().millisecondsSinceEpoch;
    final timeZoneId = settings.timeZoneId ?? _getSystemTimeZone();
    
    try {
      // 调用Rust核心
      final snapshot = await RustApi.compute(
        settings: settings.toRust(),
        holidays: holidays,
        nowUtcMillis: nowUtcMillis,
        timeZoneId: timeZoneId,
      );
      
      return snapshot;
    } catch (e) {
      // 错误处理
      rethrow;
    }
  }
  
  @override
  void dispose() {
    _timer?.cancel();
    super.dispose();
  }
}
```

```dart
import 'package:countdown_app/rust_bridge/bridge_generated.dart';
import 'package:countdown_app/rust_bridge/ffi.dart' as ffi;

class RustApi {
  static late final RustLib _lib;
  static bool _initialized = false;
  
  static Future<void> initialize() async {
    if (_initialized) return;
    
    _lib = await RustLib.init(
      externalLibrary: ffi.loadLibrary(),
    );
    
    await _lib.initApp();
    _initialized = true;
  }
  
  static Future<Snapshot> compute({
    required Settings settings,
    required HolidayData holidays,
    required int nowUtcMillis,
    required String timeZoneId,
  }) async {
    if (!_initialized) {
      throw StateError('RustApi not initialized');
    }
    
    return await _lib.compute(
      settings: settings,
      holidays: holidays,
      nowUtcMillis: nowUtcMillis,
      timeZoneId: timeZoneId,
    );
  }
```

### 6.2 难点2: 长按预览的平台差异

**问题**: 
- macOS托盘按钮需要自定义事件处理
- Windows需要全局鼠标钩子监听松开事件

**macOS解决方案**:
```swift
class StatusBarController: NSObject {
    private var statusItem: NSStatusItem!
    private var isPressed = false
    private var pressTimer: Timer?
    
    func setupStatusBar() {
        statusItem = NSStatusBar.system.statusItem(
            withLength: NSStatusItem.variableLength
        )
        
        // 自定义按钮
        let button = statusItem.button!
        button.target = self
        button.action = #selector(statusBarButtonClicked)
        button.sendAction(on: [.leftMouseDown, .leftMouseUp])
    }
    
    @objc func statusBarButtonClicked(_ sender: NSStatusBarButton) {
        let event = NSApp.currentEvent!
        
        if event.type == .leftMouseDown {
            isPressed = true
            showPreviewWindow()
            
            // 设置兜底定时器
            pressTimer = Timer.scheduledTimer(
                withTimeInterval: 30.0,
                repeats: false
            ) { [weak self] _ in
                self?.hidePreviewWindow()
            }
            
            // 监听全局鼠标松开
            NSEvent.addGlobalMonitorForEvents(matching: .leftMouseUp) { _ in
                self.hidePreviewWindow()
            }
        }
    }
}
```

**Windows解决方案**:
```dart
// 使用win32包监听全局鼠标事件
import 'package:win32/win32.dart';

class TrayController {
  int? _mouseHook;
  
  void setupTray() {
    // WinAPI钩子
    _mouseHook = SetWindowsHookEx(
      WH_MOUSE_LL,
      _mouseProc,
      GetModuleHandle(nullptr),
      0,
    );
  }
  
  int _mouseProc(int nCode, int wParam, int lParam) {
    if (wParam == WM_LBUTTONUP) {
      // 检查是否在托盘图标按下期间

        hidePreviewWindow();
      }
    }

  }
}
```

### 6.3 难点3: 时区与夏令时

**问题**: 
- 夏令时切换当天,实际经过时间与墙钟时间不一致
- 各国时区规则变化频繁

**解决方案**:

使用`jiff`库（推荐）：
```rust
use jiff::{Timestamp, TimeZone, civil::DateTime as CivilDateTime};

pub fn compute_today_worked_seconds(
    now_utc: Timestamp,
    tz_id: &str,
    work_start: Time,
) -> Result<i64, Error> {
    let tz: TimeZone = tz_id.parse()?;
    let now_local = now_utc.to_zoned(tz);
    
    // 获取今日起始时刻（本地00:00）
    let today_start = now_local.date().at(0, 0, 0, 0).to_zoned(tz)?;
    
    // 工作开始时刻
    let work_start_local = now_local.date()
        .at(work_start.hour, work_start.minute, 0, 0)
        .to_zoned(tz)?;
    
    // 实际经过的时间（秒）- 会自动处理夏令时
    let elapsed = now_utc.until(work_start_local)?.as_secs();
    
    Ok(elapsed)
}
```

**关键点**:
- 永远用UTC时间戳计算间隔
- 本地时间仅用于显示和比较
- 使用成熟的时区库,不要手写偏移

### 9.2 打包脚本

```bash
# scripts/build_release.sh

#!/bin/bash
set -e

PLATFORM=$1  # macos 或 windows

echo "Building for $PLATFORM..."

# 1. 构建Rust核心
cd core
if [ "$PLATFORM" = "macos" ]; then
  cargo build --release --target aarch64-apple-darwin
  cargo build --release --target x86_64-apple-darwin
  
  # 合并为universal binary
  lipo -create \
    target/aarch64-apple-darwin/release/libcountdown_bridge.dylib \
    target/x86_64-apple-darwin/release/libcountdown_bridge.dylib \
    -output target/release/libcountdown_bridge.dylib
elif [ "$PLATFORM" = "windows" ]; then
  cargo build --release --target x86_64-pc-windows-msvc
fi

cd ..

# 2. 构建Flutter应用
flutter build $PLATFORM --release

# 3. 签名（macOS）
if [ "$PLATFORM" = "macos" ]; then
  codesign --deep --force --verify --verbose \
    --sign "Developer ID Application: Your Name" \
    --options runtime \
    build/macos/Build/Products/Release/CountdownTimer.app
  
  # 打包为dmg
  create-dmg \
    --volname "Countdown Timer" \
    --window-pos 200 120 \
    --window-size 600 400 \
    --icon-size 100 \
    --app-drop-link 400 200 \
    "CountdownTimer-1.0.0.dmg" \
    "build/macos/Build/Products/Release/CountdownTimer.app"
  
  # 公证
  xcrun notarytool submit CountdownTimer-1.0.0.dmg \
    --apple-id "$APPLE_ID" \
    --password "$APP_SPECIFIC_PASSWORD" \
    --team-id "$TEAM_ID" \
    --wait
    
  # 装订
  xcrun stapler staple CountdownTimer-1.0.0.dmg
fi

# 4. 打包（Windows）
if [ "$PLATFORM" = "windows" ]; then
  # 使用Inno Setup打包
  iscc installer.iss
fi

echo "Build complete!"
```

## 10. 风险评估与应对

### 10.1 技术风险矩阵

| 风险项 | 可能性 | 影响 | 等级 | 应对策略 |
|--------|--------|------|------|----------|
| macOS全屏上方显示失败 | 中 | 高 | 🔴高 | M0验证；准备降级方案 |
| Rust学习曲线陡峭 | 高 | 中 | 🟡中 | 预留学习时间；外部顾问 |
| Flutter桌面内存超标 | 中 | 中 | 🟡中 | M0实测；优化图片加载 |
| 长按预览跨平台一致性差 | 高 | 低 | 🟢低 | 降级为P1 |
| 时区数据更新机制复杂 | 低 | 中 | 🟢低 | v1内置打包 |
| 节假日数据源失效 | 低 | 中 | 🟢低 | 多源备份；用户可导入 |

### 10.2 应对方案详情

#### 风险1: macOS全屏显示

**应对**:
- M0阶段用2-3天专门验证
- 测试不同macOS版本（12/13/14）
- 测试不同全屏应用（浏览器/IDE/游戏）

**降级方案**:
- 方案A: 退出全屏时自动显示
- 方案B: 仅在非全屏Space显示
- 方案C: 提供快捷键强制置前

#### 风险2: Rust学习

**应对**:
- 第一周：看官方教程 + 做练习项目
- 从简单模块开始（如生命倒计时）
- Code review由有经验的人负责
- 考虑聘请Rust顾问2-4天

**时间预算**: M1增加1周

#### 风险3: 内存超标

**M0实测计划**:
```
1. 空窗口基线内存
2. 加载3套皮肤后内存
3. 运行24小时内存增长
4. 切换皮肤10次后内存

目标: < 120MB
接受: < 150MB
超标: > 150MB → 优化或调整目标
```

## 11. 总结与建议

### 11.1 技术方案总结

✅ **优势**:
- Rust核心库保证计算正确性和性能
- Flutter保证跨平台UI一致性
- 为手机端预留了技术路径
- 清晰的模块边界便于维护

⚠️ **挑战**:
- 需要学习Rust（可控）
- macOS全屏显示需要验证（M0）
- 跨平台构建配置较复杂（一次性成本）

### 11.2 开发建议

1. **严格遵循M0验证清单**
   - 不要跳过macOS全屏验证
   - 必须实测内存和性能指标
   - 提前验证最小iOS小组件

2. **保持核心库的纯粹性**
   - 不在Rust中做IO
   - 不在Rust中读系统时间
   - 所有接口必须有单元测试

3. **持续集成很重要**
   - 每次PR必须跑测试
   - 定期跑性能基准测试
   - 及时发现内存泄漏

4. **文档优先**
   - 先写接口注释再写实现
   - 复杂算法必须有文档
   - 决策记录及时更新
