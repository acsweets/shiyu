#### F3: 实时薪资

**需求**：
- 每秒薪资 = 月薪 ÷ 当月应出勤天数 ÷ 每日有效工作秒数
- 仅工作时间内增长
- 精确到0.01元，无浮点误差
- 今日已赚 + 本月已赚

**技术实现**：
```rust
use rust_decimal::Decimal;

fn compute_salary(
    now: LocalDateTime,
    settings: &Settings,
    holidays: &HolidayData,
) -> SalarySnapshot {
    // 1. 当月应出勤天数（考虑节假日、调休）
    let work_days = count_work_days_in_month(...);
    
    // 2. 每日有效工作秒数（扣除午休）
    let daily_seconds = (work_end - work_start - lunch_duration).as_secs();
    
    // 3. 每秒薪资（Decimal运算，无精度损失）
    let per_second = monthly_salary / work_days / daily_seconds;
    
    // 4. 今日已工作秒数（扣除午休）
    let today_worked = compute_today_worked_seconds(...);
    
    // 5. 今日已赚
    let today_earned = per_second * today_worked;
    
    // 6. 本月已赚（累计已完成工作日 + 今日）
    let month_earned = accumulate_month_earned(...);
    
    SalarySnapshot { per_second, today_earned, month_earned }
}
```

**依赖库**: rust_decimal（十进制运算）  
**可行性**: ✅ Decimal保证精度  
**关键点**: 向下截断而非四舍五入

```rust
fn compute_next_holiday(
    now: LocalDateTime,
    settings: &Settings,
    holidays: &HolidayData,
) -> Option<HolidayInfo> {
    // 1. 收集所有假期：法定 + 自定义 + 周末（如开启）
    let mut all_holidays = collect_holidays(...);

    let holiday_segments = merge_consecutive_holidays(all_holidays);
    
    // 3. 找到下一个假期段
    let next = holiday_segments.iter()
        .find(|seg| seg.start > now.date())?;
    
    // 4. 目标时刻 = 该段前最后一个工作日的下班时间
    let target_time = prev_workday(next.start).at(work_end_time);
    
    Some(HolidayInfo {
        name: next.name,
        start_time: target_time,
        duration_days: next.duration(),
    })
}
```

```rust
fn compute_retire_countdown(
    now: LocalDateTime,
    retire_date: Date,
    holidays: &HolidayData,
    settings: &Settings,
) -> RetireInfo {
    let total_days = (retire_date - now.date()).whole_days();
    
    // 剩余工作日数（扣除周末和节假日）
    let work_days = count_work_days_between(
        now.date(),
        retire_date,
        &settings.work_days,
        holidays,
    );
    
    RetireInfo {
        total_days,
        total_seconds: total_days * 86400,
        remaining_work_days: work_days,
    }
}
```

### 3.1 macOS全屏应用上方显示

**挑战**: macOS全屏应用默认独占空间，普通窗口无法显示。

**解决方案（已验证可行）**: ✅

有多种成熟方案可选：

#### 方案A: NSApplicationActivationPolicyAccessory（推荐）
```swift
// AppDelegate.swift
NSApp.setActivationPolicy(.accessory)

// MainFlutterWindow.swift
window.level = .floating
window.collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]
```

**特点**:
- ✅ 可以显示在全屏应用上方
- ✅ 公开API，可上架Mac App Store
- ⚠️ 会移除Dock图标和菜单栏（但我们本来就用托盘/菜单栏）
- ✅ 知名应用案例：DropOver、Rectangle等

#### 方案B: SkyLight私有API（最强大）
```swift
import SkyLightWindow

struct ContentView: View {
    var body: some View {
        FloatingWindow()
            .moveToSky()  // 使用私有SkyLight API
    }
}
```

**特点**:
- ✅ 最强大，确保在所有情况下显示在最上层
- ✅ 开源库：[SkyLightWindow](https://github.com/Lakr233/SkyLightWindow)
- ⚠️ 使用私有API，不能上架Mac App Store（已接受）
- ✅ 支持SwiftUI集成

#### 方案C: 标准Window Level组合
```swift
window.level = .floating
window.collectionBehavior = .canJoinAllSpaces
```

**特点**:
- ✅ 纯公开API
- ⚠️ 在某些全屏应用中可能不显示
- ✅ 可上架Mac App Store

**推荐决策**:
- 如果要上架App Store → 方案A（NSApplicationActivationPolicyAccessory）
- 如果不上架（已确认）→ 方案B（SkyLight）最稳定

**可行性**: ✅ 完全可行，多个成熟应用已验证
- DropOver、Rectangle、Flycut等知名应用都实现了此功能
- 不需要M0验证，直接实施即可

### 3.5 时区与夏令时

**挑战**: 夏令时切换当天，实际经过时间与墙钟时间不一致。

**方案**: 使用jiff库自动处理
```rust
// 计算实际经过秒数
let elapsed = now_utc.until(work_start_utc)?.as_secs();
```

**关键原则**:
- 永远用UTC时间戳计算间隔
- 本地时间仅用于显示和状态判断
- 日薪固定（月薪÷应出勤天数），不受夏令时影响

**可行性**: ✅ jiff内置IANA时区数据库

### 3.6 薪资计算精度

**挑战**: 浮点运算会产生误差（0.1 + 0.2 ≠ 0.3）。

**方案**: 使用rust_decimal库
```rust
use rust_decimal::Decimal;

let per_second = Decimal::from(22000) / Decimal::from(22) / Decimal::from(28800);
let today_earned = per_second * Decimal::from(10800);  // 精确到任意位数
```

**格式化**:
```rust
// 向下截断，不四舍五入
let display = format!("{:.2}", today_earned.trunc_with_scale(2));
```

**可行性**: ✅ Decimal保证精度

### 3.7 皮肤系统的安全性

**挑战**: 用户导入的资源包可能包含恶意代码。

**安全策略**:
1. **不执行代码**: 皮肤只包含JSON配置和资源文件
2. **白名单**: 仅允许png/jpg/webp/svg/json
3. **文件头校验**: 按真实类型验证，扩展名可伪造
4. **SVG清洗**: 移除script、外部引用、foreignObject
5. **体积限制**: 单包<20MB，单图<5MB
6. **路径验证**: 禁止绝对路径、上级目录、符号链接

**可行性**: ✅ 方案成熟，参考浏览器扩展安全机制

### 4.2 数据结构

**核心数据流**:
```
用户交互 → 修改Settings → 存储JSON
    ↓
Flutter定时器(每秒) → 读取Settings + HolidayData + 系统时间
    ↓
调用 Rust compute() → 返回Snapshot
    ↓
UI渲染 → 应用Skin样式 → 显示
```

**Snapshot结构**（完整快照）:
```rust
pub struct Snapshot {
    pub timestamp: i64,                    // 计算时刻
    
    // 工作状态
    pub work_state: WorkState,             // 5种状态之一
    pub next_state_change: Option<i64>,    // 下次状态切换时刻
    
    // 薪资
    pub per_second_salary: String,         // Decimal字符串
    pub today_earned: String,
    pub today_earned_display: String,      // 截断后
    pub month_earned: String,
    pub month_earned_display: String,
    
    // 倒计时
    pub next_pay_date: String,             // ISO 8601
    pub pay_countdown_seconds: i64,
    
    pub next_holiday: Option<HolidayInfo>,
    pub holiday_countdown_seconds: Option<i64>,
    
    pub retire_remaining_days: i64,
    pub retire_remaining_seconds: i64,
    
    pub life_remaining_seconds: i64,
```

```swift
func getTimeline(completion: @escaping (Timeline<Entry>) -> Void) {
    let entries: [Entry] = (0..<60).map { minute in
        let date = Calendar.current.date(byAdding: .minute, value: minute, to: Date())!
```

```kotlin
override fun onUpdate(context: Context, appWidgetManager: AppWidgetManager, appWidgetIds: IntArray) {

        views.setTextViewText(R.id.today_earned, snapshot.todayEarnedDisplay)
        appWidgetManager.updateAppWidget(appWidgetId, views)
    }
    scheduleNextUpdate(context)  // 60秒后再次刷新
}
```
