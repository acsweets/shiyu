# 节点 07 首次引导与完整设置验收

日期 2026-11-05。前置版本为节点 06 的 `c3ef1e7`，实现版本以本报告所属 Git 提交为准。[节点计划](../../开发计划/07-首次引导与完整设置.md)

## 操作入口

- 新安装进入三步引导，依次确认个人信息、作息薪资与真实快照预览。已有合法配置直接进入原界面，未完成的引导会在下次打开时重新进入。
- 桌面从设置的「倒计时」进入「完整设置」。手机设置页顶部进入同一组个人信息、作息薪资、日期假期和通用设置。桌面还可编辑迷你窗指标顺序、显隐及自定义倒计时。
- 文本输入停顿后保存，选择分组和推进引导时先处理当前草稿。字段无效时保留草稿及提示，磁盘仍保存最近一次合法值。
- 「日期与假期」可配置六地区、三种发薪规则、日期覆盖、自定义假期，并检查或导入节假日数据。个人日期覆盖优先于其他日历来源。
- 「通用」可切换八种语言、隐藏金额、临时查看或本地导入导出。导出文件含个人信息和薪资。临时查看只在单独对话框内显示，长期偏好、主快照和共享设置保持原值。

## 复核边界

系统文件选择器实际选择路径、键盘导航和 Apple 运行留作手工复核。此节点保存桌面指标显隐和排序，真实三态浮窗在节点 08 使用该偏好。桌面外观及分组仍通过原设置导航编辑。Android 文件保存插件在当前锁定工具链构建成功，升级 Flutter 时需检查其 Kotlin Gradle Plugin 兼容性。

```powershell
./scripts/check.ps1 -BuildWindows
cd app
flutter test test/business_settings_test.dart
flutter test integration_test/retirement_test.dart -d windows --no-pub
flutter test integration_test/retirement_test.dart -d emulator-5554 --no-pub
```
