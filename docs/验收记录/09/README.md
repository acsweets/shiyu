# 节点 09 托盘与桌面平台行为验收

日期 2026-11-05。前置版本为节点 08 的 `fc40e4a`，实现版本以本报告所在提交为准。[节点计划](../../开发计划/09-托盘与桌面平台行为.md)

## 操作入口

- Windows 右键托盘图标，macOS 点击菜单栏图标。菜单可显示或隐藏浮窗、打开设置、切换金额可见性、暂停刷新、解除点击穿透、检查节假日更新及退出。开启穿透后从此菜单恢复。
- 桌面设置的「窗口管理 → 桌面行为」可切换吸附、穿透、全屏覆盖、登录时启动与金额快捷键。默认快捷键为 Ctrl/Cmd+Shift+T。金额快捷键默认关闭，可另选字母。系统拒绝注册时保留旧键位。
- 浮窗靠近工作区边缘 12 个逻辑像素时吸附。位置随显示器 ID、工作区原点和缩放保存，目标显示器缺失时回主屏右上角。
- 再启动时余会唤起现有实例的设置入口。Windows 在当前会话内限制单实例，macOS 使用 Launch Services 的重新打开事件。
- macOS 原生应用在最后一个窗口关闭后继续运行，以保留菜单栏的恢复入口。本次改动通过 Windows 临时检出中的 `scripts/check.ps1`，右键隐藏后保留图标、重新显示及主动退出待在 Mac 实测。

## 平台范围

| 项目 | Windows | macOS |
| --- | --- | --- |
| 坐标 | 原生物理坐标移动和读写，按目标屏幕 DPI 换算工作区和吸附阈值 | 窗口插件逻辑坐标 |
| 全屏 | 检测前台外部窗口是否占满所在屏幕。关闭覆盖时临时隐藏已开启的浮窗 | 默认留在原桌面空间。开启覆盖后请求加入系统允许的全屏 Space |
| 登录时启动 | 写入当前用户的 Windows 登录启动项，默认关闭 | macOS 13 及以上使用系统登录项，受系统批准控制。macOS 12 的启用开关不可用 |
| 快捷键 | 使用原生注册结果检查冲突 | 使用 Carbon 热键注册结果检查冲突 |

Windows 11 x64 当前只有一块 2560×1600 活动屏幕，窗口 DPI 为 144（150%）。混合 DPI、吸附阈值和断屏回退用固定工作区自动复现。外接多屏、其余缩放比例、真实外部全屏及注销登录后的启动行为待手工复核。Mac 构建和原生检查留给用户。

`scripts/check.ps1 -BuildWindows` 通过，含 19 项 Flutter 测试和 16 项 Rust 测试。Windows 原生 Debug 集成验证第二个进程退出并向现有窗口发送唤起事件，系统已占用的热键注册被拒绝，释放后可重新注册。原生穿透开关、模拟全屏抑制与恢复、100 次窗口显隐循环通过。

```powershell
./scripts/check.ps1 -BuildWindows
cd app
flutter test test/desktop_placement_test.dart
flutter test integration_test/retirement_test.dart -d windows --no-pub
```
