# 节点 08 桌面三态悬浮窗与指标验收

日期 2026-11-05。前置版本为节点 07 的 `ec0fc89`，实现版本以本报告所在提交为准。[节点计划](../../开发计划/08-桌面三态悬浮窗与指标.md)

## 复核方式

1. 在新用户目录启动，完成首次引导。默认迷你窗包含工作倒计时、今日已赚、放假、生命和退休。已有布局保留原有分组与示例预览偏好。要查看真实数据，关闭「示例数据」。
2. 双击浮窗卡片切换迷你与标准。在桌面「倒计时」设置中选「展开」，检查进度和日期。所有窗口同步形态，位置及分组保留，窗口尺寸按形态调整。
3. 从「完整设置 → 悬浮窗」更改顺序、显隐和自定义倒计时。从「窗口管理」可合并或拆分已开启的指标，使用原来的四个猫猫窗口槽位。更多指标可同窗滚动查看。
4. 关闭所有内置指标和自定义倒计时。主窗保留设置图标及空状态。若另行隐藏了主窗，可从托盘进入设置。
5. 开启隐藏金额，检查三态中已配置薪资显示 `****`，展开态没有薪资进度。临时查看在通用设置中单独打开。

## 自动化

- Flutter 组件测试覆盖同一快照三态一致、整行倒计时、已到期状态、窄窗滚动、金额遮蔽及空状态设置入口。旧分组、猫猫配色、字号、标题和窗口移动测试继续通过。
- Rust 回归通过。展开态工作和计薪进度使用 Rust 快照字段，金额精度仍使用原有十进制计算。
- Windows 11 x64 的 `scripts/check.ps1 -BuildWindows` 通过，含 17 项 Flutter 测试和 16 项 Rust 测试。原生 Debug Runner 集成测试实际验证显隐、双击切到标准态及窗口尺寸扩大。
- Android 16 x86_64 模拟器重新构建并通过真实 FRB 与 UniFFI 快照对照。
