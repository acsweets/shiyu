## 目标与进入条件

让浮窗能长期、安全地驻留桌面，并始终具有可恢复操作入口。

开始前核对上一节点的版本、产物、未解决问题和退出结论。上一节点不通过则先修复；不依赖后续节点补足本节点的必需能力。

## 你需要检查的点

由开发者提供可复现的操作入口和测试数据，你可按下列步骤检查。正式 UI 尚未进入开发的节点使用测试工具或临时验证入口，不伪装成已交付的产品功能。

- [ ] 隐藏浮窗、锁定穿透后分别从托盘/菜单栏恢复；正常退出后进程和系统入口消失。
- [ ] 测试显示/隐藏和金额隐藏快捷键、修改快捷键及冲突提示。
- [ ] 靠边 12px 附近拖动、关闭吸边、跨屏拖动、断开原显示器后重启，检查恢复位置。
- [ ] 在 Windows 各缩放比例与 Mac 外接屏观察窗口无漂移、不可见或过小。
- [ ] 全屏应用中分别关闭/开启覆盖，确认两桌面平台实际效果。
- [ ] 重复启动只出现一个实例；开机自启默认关闭，开启/关闭后系统行为一致。
- [ ] 暂停两分钟恢复、休眠跨过下班时刻唤醒，显示立即正确。
