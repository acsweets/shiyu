## 你需要检查的点

由开发者提供可复现的操作入口和测试数据，你可按下列步骤检查。正式 UI 尚未进入开发的节点使用测试工具或临时验证入口，不伪装成已交付的产品功能。

- [ ] 桌面正常启动直接进入迷你态，五项默认顺序和业务值正确。
- [ ] 逐项关闭、恢复、排序，最后全部开启，再缩窄窗口，确认已开启内容始终可访问。
- [ ] 双击与菜单切换三种形态，计算值、隐私状态和自定义倒计时保持一致。
- [ ] 创建一项短倒计时，观察按秒变化、到期只显示已到期且不出现负数。
- [ ] 隐藏所有金额，在三种形态逐一查看，不能在进度条旁或次要文本泄漏。
- [ ] 退出重启后显示选择和排序不变；缺少设置时有可靠的引导/设置入口。
