## 开发 TODO

- [x] 实现 iOS WidgetKit/SwiftUI 和 Android Glance 或 RemoteViews；两平台通过 UniFFI 调用同一 Rust 核心。
- [x] 倒计时 widget 支持距离下班、放假、发薪、退休四类指标；不包含生命或自定义倒计时扩展范围。
- [x] 根据系统能力采用 timeline/系统计时显示，在边界重新计算；支持平台可用的紧凑与宽尺寸，窄空间展示用户选择主指标。
- [x] 薪资 widget 显示今日/本月已赚，按约每分钟策略请求更新，展示“约 X 分钟前更新”，不保证系统严格每分钟执行。
- [x] 从共享容器读取设置与假日数据独立计算，主应用退出/未启动仍可显示；处理旧版本/数据损坏的回退状态。
- [x] 同步隐藏金额偏好，以 **** 遮蔽；主应用临时查看不解除 widget 遮蔽。
- [ ] 设置变更后请求系统刷新；测试休息/午休/跨日/发薪/放假边界与时区变化。
- [x] 实现添加、移除、重新配置、多实例与尺寸变化的生命周期，避免只在某个 launcher/机型可用。
- [x] 记录平台后台/锁屏刷新限制和实际延迟，不把未调度时的旧值伪标为刚刚计算。

## 你需要检查的点

由开发者提供可复现的操作入口和测试数据，你可按下列步骤检查。正式 UI 尚未进入开发的节点使用测试工具或临时验证入口，不伪装成已交付的产品功能。

- [ ] 两平台分别安装倒计时和薪资组件，核对四类指标及紧凑/宽尺寸行为。
- [ ] 关闭主应用后等待并跨过业务边界，组件仍能读取本地数据与 Rust 结果；核对显示更新时间。
- [ ] 修改作息或薪资，重新请求刷新后组件采用新值；系统延迟时显示上次计算时间。
- [ ] 启用隐藏金额，组件全部显示 ****；主应用临时查看不泄漏到桌面 widget。
- [ ] 调整系统时间/时区、重启/进程回收和离线后检查状态；组件中不存在自定义倒计时入口。
- [ ] 至少在 iOS 最低/当前支持环境与 Android 不同 launcher/尺寸上查看实际效果。
