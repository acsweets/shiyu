## 你需要检查的点

由开发者提供可复现的操作入口和测试数据，你可按下列步骤检查。正式 UI 尚未进入开发的节点使用测试工具或临时验证入口，不伪装成已交付的产品功能。

- [ ] 查看四平台构建产物和命令日志；确认对应平台能启动，不能用 Windows 构建替代 Mac/iOS 验证。
- [ ] 在 Windows 和 Mac 演示透明、拖动、置顶、穿透后从系统入口恢复操作。
- [ ] 在 Mac 全屏应用中切换覆盖开关，核对实际行为和已知限制。
- [ ] 安装两个平台最小 widget，核对显示内容确实来自 Rust 原生调用，而非 Swift/Kotlin 写死。
- [ ] 查看六地区数据来源/许可和风险表；缺少设备或数据源时看到明确阻断，未标成通过。
