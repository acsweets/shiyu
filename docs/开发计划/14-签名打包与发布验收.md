## 目标与进入条件

形成可安装、可升级、可回退的正式候选包，完成 G5；外部发布仍按实际发布授权执行。

开始前核对上一节点的版本、产物、未解决问题和退出结论。上一节点不通过则先修复；不依赖后续节点补足本节点的必需能力。

- [ ] 生成 Windows 安装包、macOS 签名/公证产物、iOS 与 Android 签名包；小组件扩展随应用正确分发。

## 你需要检查的点

由开发者提供可复现的操作入口和测试数据，你可按下列步骤检查。正式 UI 尚未进入开发的节点使用测试工具或临时验证入口，不伪装成已交付的产品功能。

- [ ] 下载或取得最终签名包，在目标系统按普通用户流程完成安装，确认不是仅 IDE 能运行。
- [ ] 桌面初次启动默认迷你五项；移动应用和两类组件能配置、离线显示且金额隐私一致。
- [ ] 从上一版升级保留设置，自定义倒计时和显示排序不丢；失败后按回滚文档恢复。
- [ ] 核对每个平台版本号、签名、架构、widget entitlement/权限和文件校验和。
- [ ] 查看最终功能清单、已知问题、数据许可、性能与长稳报告，确认与候选包对应。
- [ ] 确认对外发布渠道、账号与范围后再执行实际发布；未发布时状态明确写为候选已验收。
