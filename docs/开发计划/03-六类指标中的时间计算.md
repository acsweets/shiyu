## 开发 TODO

- [x] 实现休息日、未上班、工作中、午休中、已下班状态及相应下一目标时间；支持关闭午休，拒绝跨零点夜班。
- [x] 生命目标按日历年计算，出生时刻缺省为 00:00，寿命默认 100 年、1–150 年且一位小数；2 月 29 日遇非闰年按 2 月 28 日。
- [x] 实现寿命超过目标时的明确状态；小数寿命按相邻生日之间的实际公历日数折算，样例见[数据契约](../技术说明/数据契约-v1.md)。
- [x] 退休目标使用用户输入日期，支持当天/过期状态，不自动推算退休政策。
- [x] 实现固定日、最后工作日、每月两次发薪；短月取月末，休息日支持提前/顺延/不调整，默认顺延。
- [x] 处理发薪日当天、跨月调整、同日目标去重和下次目标切换，避免同一发薪事件重复计次。
- [x] 合并周末、法定节假日与自定义假期的连续休息段；每周休息日算放假默认开启且可关闭。
- [x] 未放假时目标为前一个工作日下班时刻；放假中返回结束时间与下一段休息信息。
- [x] 完善 Snapshot 与 next_change_at，剩余数值不为负；年/月/日等展示所需日历信息通过统一契约提供，UI 不复制日期业务。
