## 你需要检查的点

由开发者提供可复现的操作入口和测试数据，你可按下列步骤检查。正式 UI 尚未进入开发的节点使用测试工具或临时验证入口，不伪装成已交付的产品功能。

- [ ] 查看一份 Settings JSON 与 Snapshot JSON，能够分辨输入、原始数值、错误状态和下一变化时间。
- [ ] 用同一固定时间重复计算，结果完全一致；改变机器时区但保持输入时区不变，结果不应无故改变。
- [ ] 把周六覆盖为工作日、把周一覆盖为休息日，确认覆盖优先级最高。
- [ ] 移除节假日数据，看到按周工作日回退及缺失状态，而非计算失败或假装有完整数据。
- [ ] 输入跨零点夜班或无效时区，看到字段错误且错误内容不含薪资。
