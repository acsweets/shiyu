## 校验与更新

- 启动先读内置和本地有效数据，再异步请求 [项目固定日历文件](https://raw.githubusercontent.com/acsweets/shiyu/main/app/assets/holidays/calendar.json)。同一个 HTTPS GET 下载六地区，无请求体、账号、个人配置、所选地区或薪资。拒绝重定向，限制 128 KiB 和超时时间。
- 包含完整六地区的下载包通过校验后原子替换缓存。每个地区选择最新有效版本，同版本的不同内容和覆盖年份倒退均被拒绝。读取失败时回退到有效缓存或内置数据，再按周工作日计算。
- 手动导入由用户选择单地区 JSON。应用检查 schema、地区、日期、声明来源域名和 SHA-256。摘要用于检查完整性，手动文件的来源由选择文件的用户判断。联网更新以固定 HTTPS 项目仓库作为发布来源。
- SHA-256 输入为 UTF-8 编码的紧凑 JSON 数组 `[version, payload]`，保留 `payload` 对象键顺序，分隔符为 `,`、`:`。不含 BOM、换行或空格。核心仅收到 `schema_version`、`region`、`years` 和 `date_overrides`。

## 维护

`python scripts/build_holiday_catalog.py` 按核对后的日期生成内置/联网共用文件。更新发布年份时，先更新日期与来源，再增版本并校验两年数据。节点 11 将有效的核心日历 JSON 和版本同步到小组件共享容器。

可从项目日历提取单地区文件进行离线导入。在仓库根目录执行以下命令，替换地区代码即可。

```powershell
python -c "import json,pathlib; a=json.loads(pathlib.Path('app/assets/holidays/calendar.json').read_text(encoding='utf-8')); pathlib.Path('CN.json').write_text(json.dumps(a['packs']['CN'],ensure_ascii=False),encoding='utf-8')"
```
