日期：2026-11-04。依据：用户在开发中明确要求“当前平台和 Android 上运行成功为第一个里程碑”，macOS/iOS 由用户后续在 Mac 上验证。

## 本次范围

节点 01 的完成门槛调整为 Windows 与 Android 实际构建、启动和真实 Rust 调用通过；Apple 平台提交对应构建适配器、生成绑定、脚本和复核清单，保留待用户验证状态。不能把这次里程碑通过描述为原始计划的四平台 G0 全部通过。

原节点 01 中未纳入当前运行里程碑的事项继续安排在既有节点：时间语义与日历版本在 02、节假日来源许可与更新链路在 06、完整桌面窗口/全屏策略在 09、正式原生小组件与共享容器在 11/12。它们保持未完成，不以本次最小探测替代验收。Apple 复核发现的问题回填节点 01 并优先修复，但等待 Mac 实测不阻断 Windows/Android 后续开发。

## 模块边界与最小协议

- `shiyu_core` 保持纯 Rust，当前只有 `bridge_probe(u32) -> String`：返回 `shiyu-core:<输入加一并按 u32 环绕>`，不包含计薪或日历算法。
- `shiyu_bridge` 为 FRB 适配器。Flutter 普通入口先执行 `RustLib.init()`，实际加载打包的 Rust 库。
- `shiyu_ffi` 为 UniFFI 门面，调用同一 engine；`shiyu_bridge` 重导出其符号，原生 Kotlin 可从同一份打包库调用。
- `shiyu_bindgen` 独立于运行时，固定 CLI 依赖。Swift/Kotlin 生成文件随仓库保存，禁止手改。
- Flutter 集成测试使用 41、0、u32 最大值三个输入核对返回结果；Android 调试通道另外验证 Kotlin → UniFFI → Rust，避免只测到 Dart 层 mock。
- `lib/main_probe.dart` 为显式开发入口；托盘、快捷键和穿透验证不进入普通产品首页。Android 探测 widget 只在 debug 源集中注册，不属于正式产品组件。

## 构建适配

采用 FRB Cargokit 源码构建并打包 Rust，不引入预编译业务库。模板针对 Rust 数字版本、Gradle 9、当前 SDK 的补丁见 [SHIYU_PATCHES](../../app/rust_builder/SHIYU_PATCHES.md)。Windows 的 `ShowWindowAsync` 是异步系统调用，窗口测试有限等待可见状态后断言，不把插件通道返回当成显示完成。

本机全局 Gradle 代理端口为不可用的 7891；实际可用端口为 7890。本次只在专用 Gradle user home 中覆盖代理，不修改全局 `.gradle/gradle.properties`。长路径缓存曾导致 Kotlin DSL 无法读取依赖，验证使用短路径 `C:/Users/19814/.gradle-shiyu`，缓存不提交。其他机器按自身网络与缓存配置运行，不应照搬本机代理端口。
