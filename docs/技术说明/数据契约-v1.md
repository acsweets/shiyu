# 数据契约 v1

实现：`core/crates/engine/src/`，FRB 与 UniFFI 只转发同一 Rust 实现。所有 JSON 使用 snake_case、UTF-8，当前 schema_version 为 1。公共签名为字符串，以免各端生成器分别定义业务规则。

## 入口

| Rust 入口 | 入参 | 返回 |
| --- | --- | --- |
| default_settings | 无 | 完整默认 Settings JSON |
| validate_settings | settings_json | 成功 `{ok:true,settings:规范化设置,errors:[]}`；失败 `{ok:false,errors:[{field,code}]}` |
| compute_snapshot | settings_json、holiday_json、now_millis(i64) | 成功 `{ok:true,snapshot:{…},errors:[]}`；失败 `{ok:false,errors:[{field,code}]}` |

now_millis 是调用方传入的 Unix UTC 毫秒，不能来自各算法内部的当前时间。工作日与目标日期均使用设置中的 IANA 时区；设备所在时区不参与业务规则。

## Settings

省略的顶层字段补为下列默认值；可选子对象内的必填字段缺失、未知字段、错误 JSON 类型均拒绝。十进制输入必须是字符串，不能写成 JSON 浮点数。

```json
{
  "schema_version": 1,
  "time_zone": "Asia/Shanghai",
  "region": "CN",
  "retirement_date": null,
  "birth": null,
  "schedule": {"workdays": [1,2,3,4,5], "start": "09:00", "end": "18:00", "lunch": ["12:00","13:00"]},
  "salary": null,
  "payday": null,
  "weekly_rest_as_holiday": true,
  "date_overrides": {},
  "holidays": [],
  "custom_countdowns": [],
  "hide_amount": true
}
```

| 字段 | 约束与语义 |
| --- | --- |
| region | CN/US/JP/KR/HK/TW；当前六地区基础周工作日均为周一至周五，法定假日数据不在本节点内置 |
| retirement_date | null 或公历 YYYY-MM-DD；以该日设置时区 00:00 为退休时刻，用户直接填写 |
| birth | `{date,time?,life_expectancy_years}`；寿命为 1–150、至多一位小数的字符串。仅校验输入，节点 03 实现生命指标 |
| schedule | ISO 星期 1–7，可选任意不重复子集；start < end，禁止跨夜；lunch 为 null 或位于工作区间内且起点早于终点的二元组 |
| salary | `{gross_monthly,net_monthly?,currency,precision,basis?}`；金额非负十进制字符串、币种三位大写、精度 2–4；basis 默认为 gross，可为 net，后者需提供税后月薪。节点 04 才计算薪资 |
| payday | `{rule,days,adjustment}`；fixed_day 一项 1–31、last_workday 空数组、twice_monthly 两项不同的 1–31；adjustment 为 next_workday/previous_workday/none。仅契约与校验，目标日计算见节点 03 |
| date_overrides | 日期 → bool，true 为工作日、false 为休息日 |
| holidays | `{name,start,end,kind}` 数组；起止日期包含边界、start ≤ end、名称非空；当前所有自定义假期均作为休息日，不表示带薪/无薪 |
| custom_countdowns | `{id,name,target}` 数组；id 唯一非空、名称非空、target 为本地公历日期时间；节点 04 计算，仅桌面后续提供 CRUD |

当前 UI 仅编辑退休日期与时区，保存时保留其余已知字段。移动 widget 只读取退休字段；不显示自定义倒计时或金额。

## 日历输入与优先级

无数据使用 `{}`。有数据的结构：

```json
{"schema_version":1,"region":"CN","years":[2026],"date_overrides":{"2026-11-07":true,"2026-11-09":false}}
```

上述为合成验收样例，不是法定日历。只有 schema、地区及年份匹配才使用地区日期覆盖。覆盖优先级：**个人日期覆盖 > 自定义假期 > 地区日期覆盖 > 每周工作日**。重叠自定义假期都表示休息日；无额外优先级。工作周中七天可任意勾选。

缺地区/年份数据时仍使用个人覆盖、自定义假期和工作周，calendar_status 为 weekly_fallback；匹配数据为 available。当前产品固定传 `{}`，不会假装已经有法定节假日。数据来源、数据修订号、下载/缓存/授权均由节点 06 负责。

## Snapshot

```json
{
  "schema_version":1,
  "computed_at_millis":1793764800000,
  "local_date":"2026-11-04",
  "time_zone":"Asia/Shanghai",
  "is_workday":true,
  "calendar_status":"weekly_fallback",
  "next_change_at_millis":1793808000000,
  "retirement":{"status":"active","target_millis":1793808000000,"remaining_seconds":43200,"remaining_days":1},
  "unavailable_metrics":["life","work","salary","payday","holiday"]
}
```

该例退休日期为 2026-11-05。`remaining_days` 是两地历日期的差，不能拿秒数除 86400；跨 DST 时一天可以是 23/25 小时。`remaining_seconds` 向上取整且不小于零，到期状态 retired；无目标为 unconfigured、target_millis=null，UI 显示待配置而非真实的零倒计时。

next_change_at_millis 当前是下一本地午夜与未来退休时刻中较早者，供日历天数 widget 调度；不意味着秒级数据在该时刻前不变。前台每秒使用真实 now 重算，停止期间不累加 tick。暂未实现的指标用 unavailable_metrics 明示，不能使用零填充为产品数据。

## 时区、错误与兼容

- jiff 0.2.39 启用 tzdb-bundle-always，四端使用锁文件固定的时区数据库，避免依赖手机/桌面系统数据库。时区更新随应用核心版本发布。
- 本地目标午夜重叠或不存在时明确拒绝：`ambiguous_local_time`，不自动偏移到另一日。下一日历边界不可解析时快照返回相同错误，不猜测边界。DST、闰年与月末样例位于 Rust 测试；小数寿命算法尚未实现。
- 验证失败只返回字段路径和稳定错误码，不携带原始个人值；计算阶段对非法设置返回 settings/invalid_settings。常用码：invalid_json、too_large、unsupported_version、invalid_date、invalid_time_zone、invalid_workdays、invalid_work_hours、invalid_lunch、invalid_amount、invalid_precision、invalid_paydays、net_salary_required、invalid_timestamp、out_of_range。
- Settings 上限 128 KiB；Android/iOS 共享读取有同样上限。未知字段拒绝，未来 schema 拒绝。省略当前字段只补默认，不表示跨版本迁移已实现。
- 新安装不保存虚构生日、薪资或退休日期。无文件加载默认；损坏/未来版本文件保留原件并禁止当前 UI 写入。节点 05 再引入显式版本迁移、备份/恢复及用户可操作的修复流程，不静默降级覆写。
- 桌面使用同目录临时文件后 rename；Android 使用 AtomicFile 回滚；iOS 使用 App Group 文件 Data.write(.atomic)。无账号或配置上传。

共享黄金样例：`core/testdata/retirement_cases.json`；Rust 测试固定 now，原生集成测试在同一 now 比较 FRB 与 Android UniFFI 的完整响应。Apple 的 Swift 主机探测也包含固定退休样例，需在 Mac 运行。
