## 开始开发

2026-11-05 用户确认当前整体设计和风格，并指示进入节点 03。[项目记录](项目记录/README.md)保存本次设计阶段结束时的功能、视觉和工程基线。

进入[开发计划与里程碑](开发计划/README.md)，按 00 → 14 顺序推进。02 的退休浮窗与主屏幕小组件仍保留平台验收清单，当前开发[节点 03 时间计算](开发计划/03-六类指标中的时间计算.md)。每个节点记录开发 TODO、用户检查点、验证方式、交付物和退出条件。
