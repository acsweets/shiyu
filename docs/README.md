## 开始开发

进入[开发计划与里程碑](开发计划/README.md)，按 00 → 14 顺序推进。00 记录工程基线，01 已完成 Windows/Android 运行里程碑，下一项开发是 02。每个节点有独立文档，包含开发 TODO、你要检查的点、验证方式、交付物和进入下一节点的条件。Apple 验证由用户后续在 Mac 执行并回填。

| 位置 | 内容 |
