## 开始开发

进入[开发计划与里程碑](开发计划/README.md)，按 00 → 14 顺序推进。00 记录工程基线，01 已完成 Windows/Android 运行里程碑，当前节点 02 已实现退休浮窗与原生小工具切片，待第二检查点验收。每个节点有独立文档，包含开发 TODO、你要检查的点、验证方式、交付物和进入下一节点的条件。用户已反馈上个节点 Mac 验证就绪；本节点新增 Apple 代码仍由用户在 Mac 执行并回填。
