## 视觉和交互规格

### 桌面

- 2D 手绘橘猫贴住浮窗上沿。四个窗口槽位依次使用坐姿、伸懒腰、挥爪、蜷睡。同一窗口共用一只猫，合并到目标槽位时沿用目标姿态。
- 每项上方是标题，下方完整显示一个倒计时。一个窗口内所有计时项共用一块底色。马卡龙、冷酷和日落暖调提供按槽位变化的底色；浮窗上保留必要的倒计时信息和主窗齿轮。
- 目前有下班、放假、发薪、退休四个槽位，可合并或拆成四个独立窗口。默认效果预览使用固定示例；关闭预览后退休读取真实数据，其他槽位在此基线提示待接入。
- 窗口最小尺寸为 260 × 146 逻辑像素，合并多个项目后可缩放或在窗口内滚动。设置里可分别隐藏窗口和标题，并保留分组与位置。主窗隐藏后用托盘或菜单栏找回设置，Ctrl/Cmd+Shift+T 统一收起或恢复已启用窗口。
- 独立设置窗使用统一白底、粗体、细描边和陶土色强调。左栏固定导航分为外观、窗口管理、倒计时、猫猫素材。右侧内容滚动，色卡有内边距，分组移动可撤销。标题字号 10–24，默认 13，倒计时数字使用独立字号。
- 可用透明 PNG 替换编号槽位的猫。图片尺寸、透明留白、命名和检查方式见[用户资源制作指南](../界面设计/04-用户资源制作指南.md)。

### 手机

- 应用打开即进入白底设置。三个分组分别负责退休日期与时区、主屏幕添加入口、组件外观。Android 启动器支持时可由应用发起添加，iOS 从系统小组件图库添加。
- 系统主屏幕上的猫猫贴住整卡上沿，标题与倒计时上下排列，倒计时的天和时分秒同一行。未配置显示设置日期提示，到期显示已退休。三套配色、标题显隐与 10–24 的标题字号由设置同步给原生组件。
- Android 显示最近一次计算的快照，定期更新由系统调度，保存设置请求刷新。iOS 使用 WidgetKit 时间线，源码在 iOS 16 及以上为最后一天提供系统计时文字。
- 主屏幕的位置与显隐由系统管理，手机应用的职责是配置退休目标和小组件外观。

## 真实业务和待开发范围

基线 Rust 已计算退休状态、绝对目标、剩余秒数和日历天数。工作日判定支持个人日期覆盖、自定义假期、地区日期覆盖和工作周回退。地区法定假日包、完整生命/作息/发薪/放假计算、薪资、自定义倒计时管理、完整三态、四指标及薪资组件按后续节点推进。当前产品入口仅编辑退休日期和时区，保留已存在的其他合法设置。
