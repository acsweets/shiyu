## 四平台能力

| 场景 | Windows | macOS | Android | iOS |
| --- | --- | --- | --- | --- |
| 应用内查看时间和薪资 | 置顶浮窗，支持迷你、标准和展开 | 共用桌面 UI 和计算，当前桌面行为待复核 | Flutter 首页，API 36 模拟器实测 | 共用移动首页，待在 Mac 和设备上验证 |
| 主屏幕或桌面展示 | 独立浮窗可合并、拆分、拖动和缩放 | 独立浮窗，置顶与全屏空间由原生窗口处理 | 倒计时与薪资小组件，依赖启动器 | WidgetKit 小、中尺寸，依赖 App Group 与扩展签名 |
| 配置目标和计算规则 | 浮窗齿轮进入设置，完整设置包含业务表单 | 菜单栏和主窗均能打开设置 | 首页齿轮进入按任务分组的设置 | 同一移动设置，通过原生桥写入共享容器 |
| 自定义倒计时 | 完整设置可创建、编辑、删除和显隐 | 共用桌面入口，待实机验证 | 移动首页和小组件展示预设指标 | 移动首页和小组件展示预设指标 |
| 系统入口 | 托盘、快捷键、原生单实例和登录启动 | 菜单栏、快捷键、全屏空间和登录项，登录项要求 macOS 13+ | 应用内请求添加组件或由启动器添加 | 主屏幕图库添加，iOS 17+ 支持编辑通用倒计时组件 |
| 配色和语言 | 四套色板、皮肤、PNG 与资源包，应用八种语言 | 同一套桌面设置和外观模型 | 四套组件色板，应用八种语言，组件中英文 | 四套组件色板，应用八种语言，组件中英文，部分系统配置项沿用英文 |

四平台应用共用手绘橘猫图标。桌面与移动设置沿用白底、粗体和陶土色强调。原稿与平台图标文件见[品牌资源说明](../../app/assets/brand/README.md)。移动端的浮窗体验由系统主屏幕小组件提供，Flutter 应用内展示完整首页。

## 指标与计算口径

| 指标 | 当前行为 | 主要实现 |
| --- | --- | --- |
| 作息 | 按当前日期、工作时段和午休，切换至距离上班、午休结束或下班。配置支持工作周和日期覆盖 | [工作指标](../../core/crates/engine/src/metrics/work.rs) |
| 今日已赚、本月已赚 | 用户设置税前或税后月薪、币种和显示精度。按月内应出勤日与当日实际工作时段累计，午休暂停，最终金额截断。隐藏时显示 `****` | [薪资指标](../../core/crates/engine/src/metrics/salary.rs) |
| 发薪 | 支持指定日和每月最后工作日，短月与休息日按配置调整。发薪当天显示当前状态 | [发薪指标](../../core/crates/engine/src/metrics/payday.rs) |
| 放假 | 结合个人和地区日历显示距离下个假期或假期结束。地区数据缺失时继续使用个人配置和工作周 | [假期指标](../../core/crates/engine/src/metrics/holiday.rs)、[日历规则](../../core/crates/engine/src/calendar.rs) |
| 退休 | 按配置时区的目标日期计算剩余日历天数和秒数。未填目标提示设置，到期显示已退休 | [快照组装](../../core/crates/engine/src/snapshot.rs)、[时间指标入口](../../core/crates/engine/src/metrics/mod.rs) |
| 生命 | 「静待百岁，好好生活」按出生日期、可选出生时间和设置的预期寿命计算目标。「已存在世界」按出生日期至当前时区日期计天，出生当天为 0，午夜更新。上方是标题，下方只显示如 `1,234 天` | [生命指标](../../core/crates/engine/src/metrics/life.rs)、[指标显示](../../app/lib/features/retirement/presentation/metrics/snapshot_metrics.dart) |
| 自定义倒计时 | 桌面完整设置管理独立目标，Rust 校验并计算。启用项进入桌面展示，可单独隐藏标题，过期后保留条目 | [自定义设置](../../app/lib/features/retirement/presentation/settings/custom_countdown_settings.dart)、[自定义倒计时写入](../../core/crates/engine/src/custom_countdown.rs) |

日期和金额规则见[数据契约](../技术说明/数据契约-v1.md)。按快照字段统计，七个内置显示项包含两条薪资行。

## 手机首页与设置

- 首页以作息为主卡，其余六条内置指标使用自适应网格。窄屏或系统字号较大时使用单列。活动倒计时和计薪中的金额在前台整秒重算，右上角刷新按钮也会请求系统刷新已添加的小组件。[首页实现](../../app/lib/features/retirement/presentation/mobile_dashboard.dart)
- 首次安装有个人信息、作息与薪资、真实快照三步引导。进入首页后，从右上齿轮直达「倒计时」「作息与薪资」「日期与假期」「逐项显示标题」「主屏幕小组件」和「通用」。生命模式、出生信息和退休日期在倒计时页，时区可在通用中设置。[应用入口](../../app/lib/app/shiyu_app.dart) · [设置首页](../../app/lib/features/retirement/presentation/mobile_settings_page.dart)
- 分类表单从底部保存，时刻可点选。提交失败留在原页并保留草稿，离开有未保存修改的页面时可以确认放弃。设置备份可从通用导入导出，出现损坏状态且有合法备份时可恢复。[分类表单](../../app/lib/features/retirement/presentation/mobile_settings_detail.dart)
- 应用语言支持跟随系统、简体中文、繁体中文、英语、日语、韩语、西班牙语、德语、法语。移动应用、真实指标、完整设置及桌面设置导航使用本地化；部分桌面细项仍显示中文。[本地化说明](../../app/lib/l10n/README.md)
- 小组件页集中提供添加指引、配色、标题总开关和字号。单项标题由业务设置控制，组件标题总开关影响倒计时标题；薪资标题使用各自的逐项设置。[小组件设置](../../app/lib/features/retirement/presentation/mobile_widget_settings_page.dart) · [外观表单](../../app/lib/features/retirement/presentation/mobile_appearance_panel.dart)

## 系统小组件

| 能力 | Android | iOS |
| --- | --- | --- |
| 倒计时选择 | 点击卡片为该实例勾选 1 至 4 项，保存后在同一张卡片显示，旧实例在首次编辑前沿用原布局 | iOS 17+ 通用组件可在主指标后追加最多三项，重复项合并为一条。iOS 15 和 16 保留固定组件和中尺寸预设 |
| 薪资 | 小、宽两种布局显示今日和本月已赚。点卡片内猫猫下方的按钮，直接从当前设置重算金额 | 小、中两种布局。iOS 17+ 卡片内猫猫下方的按钮请求系统重建时间线，iOS 15 和 16 可在应用首页手动刷新 |
| 活动计时 | 有目标时使用启动器中的 `Chronometer`。Rust 提供目标和下次状态变化，系统闹钟请求重算。启动器或省电模式可能延后到期更新 | iOS 16+ 可用 SwiftUI 系统计时文字，旧系统使用时间线快照。组件更新时间由 WidgetKit 调度 |
| 卡面 | 猫猫贴纸、背景色板、标题及数值，标题显隐支持逐项设置 | 同类卡面，使用 SwiftUI 自适应文字 |
| 加载配置 | 应用私有文件，由原生提供者调用 UniFFI；与 Flutter 应用同一安装包 | 独立 WidgetKit 扩展，通过 App Group 读设置、外观和地区数据，再调用 UniFFI |

薪资组件约一分钟请求重算，系统可延后。Android 的倒计时递减、四项合并、玻璃色板和薪资手动刷新已在 API 36 启动器实测。iOS 渲染、组件编辑和时间线分支待实机复核。

## 当前验证边界

- Windows 11 Release 已构建运行，复核了原布局恢复、主倒计时显示、设置窗口、逐项标题相关逻辑与新色板入口。多屏、休眠和各 DPI 组合仍按节点 13 检查。
- Android API 36 x86_64 Release 已安装启动，应用设置、主屏幕小组件、玻璃配色和计时刷新有验收记录。近期文案已确认进入 APK；ARM64 真机、最低 API 和省电状态需要独立验证。
- macOS 有早期运行反馈，当前桌面原生行为待复测。iOS 的宿主、共享容器、扩展和时间线已接入源码，需在 Mac 完成构建、签名和设备验证。
- 节点 13 仍在回归，内存、冷启动和连续七天运行未达到或尚未完成全部验收。节点 14 的正式签名、分发及回滚检查待开始。[节点 13 记录](../验收记录/13/README.md) · [发布节点](../开发计划/14-签名打包与发布验收.md)
