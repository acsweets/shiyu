## 记录原则

- “已确认”只记录用户明确表达的要求；助手提出的配色、角色位置、默认主指标、整体移动等建议保留为待讨论。
- 当前绿色配色及旧布局不作为新视觉的定稿依据。最终配色、角色、尺寸和交互细节尚未确定。
- 本轮只讨论并保存文档。未生成正式设计图、角色资产或资源包，未修改 Flutter、Rust 或原生功能代码。
- 此处是冻结需求之后的新设计输入，可能影响节点 08–10 的浮窗/皮肤设计。当前不覆盖历史冻结文档，不提前决定三态与自由布局如何对应。
- 当前确认的自由摆放针对桌面浮窗；手机应用与 Android/iOS 系统小工具的布局需要另行讨论。
