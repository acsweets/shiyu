## 记录原则

- “已确认”只记录用户明确表达的要求；助手提出的配色、角色位置、默认主指标、整体移动等建议保留为待讨论。
- 当前绿色配色及旧布局不作为新视觉的定稿依据。默认角色已确定为猫猫；具体造型、最终配色、尺寸和交互细节尚未确定。
- 最初讨论阶段仅记录文档。2026-11-05 按用户指示增加桌面首版与独立猫猫素材；资源包、其他业务算法和移动端重做未实施。
- 此处是冻结需求之后的新设计输入，可能影响节点 08–10 的浮窗/皮肤设计。当前不覆盖历史冻结文档，不提前决定三态与自由布局如何对应。
- 手机倒计时放在系统主屏幕小组件，应用内是白底配置页。操作和验收见[手机主屏幕小组件与设置](08-手机浮窗与设置.md)。
