# 手机主屏幕小组件与设置

手机上的猫猫倒计时位于 Android 和 iOS 的系统主屏幕。打开时余直接进入白底设置。组件读取本机共享配置，独立调用 Rust 计算退休倒计时。

## 主屏幕小组件

- 橘猫贴住彩色卡片上沿。标题在上，完整倒计时在下，天与时分秒同一行。未配置时提示设置日期，达到目标后在更新时显示「已退休」。
- 通过系统启动器或 iOS 小组件图库添加、移动和移除。Android 支持启动器提供的尺寸调整，iOS 提供小、中尺寸。点击组件打开时余。
- Android 在保存日期、时区或外观时请求刷新，并保留 30 分钟的系统刷新周期。iOS 通过 WidgetKit 时间线请求更新，iOS 16 及以上的最后一天可用系统计时文字显示剩余时间。长周期显示最近一次计算的快照。

## 应用设置

| 分组 | 可用操作 |
| --- | --- |
| 退休倒计时 | 选择或清除退休日期，输入 IANA 时区，点击「保存设置」一起提交 |
| 主屏幕小组件 | 查看系统添加说明。支持的 Android 启动器可以从应用发起添加请求 |
| 小组件外观 | 三套整卡配色、标题开关、10–24 的标题字号。已添加的组件使用同一份外观设置 |

页面采用白底、粗体和陶土色主按钮。旧版应用内卡片保存的配色、标题显隐和字号会迁入组件外观。主屏幕位置由系统管理。
