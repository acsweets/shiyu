# 手机浮窗与设置

Android 和 iOS 的首页使用应用内浮窗。打开首页可查看退休倒计时，右上角的齿轮始终可进入设置。主屏幕小组件通过系统添加，可在离开应用后查看退休剩余天数。

## 首页

- 白色页面上只保留一个倒计时浮窗。橘猫贴住浮窗上沿，卡片从上至下显示标题和一行完整倒计时。卡片底色与桌面使用同一套色卡。
- 拖动猫猫或卡片可在首页的安全区域内摆放。位置按可用空间的比例保存，横竖屏切换和重启后仍可查看。设置里可重置位置。
- 未配置日期时显示「—」，并在卡片下方提供选择日期的入口。到期时显示「已退休」。剩余时长来自 Rust，按整天和时分秒显示，前台每秒刷新。

## 设置

| 分组 | 可用操作 |
| --- | --- |
| 退休倒计时 | 通过日历选择或清除日期，输入 IANA 时区，点击「保存设置」一起提交。保存后首页刷新，并请求系统刷新已添加的小组件 |
| 外观 | 切换马卡龙色系、冷酷色系或日落暖调，显示或隐藏浮窗和标题，调整标题字号为 10–24，重置浮窗位置。外观即时应用，在当前手机上保存 |
| 主屏幕小组件 | 查看手动添加说明。Android 启动器支持时，可以在应用内请求添加。iOS 通过主屏幕的小组件图库添加 |

页面为白底和粗体，陶土色用于主操作及选中状态。分组采用单列滚动，日期、时区和保存操作相邻。色卡有独立描边、选中标记和内边距。
