# 01：视觉方向

[设计目录](README.md)

状态：讨论记录，未定稿。日期：2026-11-04。

## 已确认

- 使用 **2D 手绘小角色／贴纸感**。
- 默认角色为**猫猫**。具体品种、毛色、服饰、表情和姿态尚未确定；用户以后可以按资源规范自行制作替换素材。
- 当前浮窗的整体绿色主题和布局不符合用户预期，需要重新设计。
- 视觉需要体现 Q 版气质；角色、贴纸外形和内容排版共同形成风格。
- 倒计时是主要信息，具体结构见 [浮窗布局与交互](02-浮窗布局与交互.md)。

## 已提出、尚未确认的建议

以下是讨论中的候选，不视为用户已选定的风格规范。

| 方面 | 候选方向 |
| --- | --- |
| 底色 | 奶白或暖灰，具体纸张质感待设计图比较 |
| 点缀色 | 杏橙、浅蓝等候选；尚无最终色板或色值 |
| 贴纸边缘 | 轻微手绘弧度、描边和轻投影，具体粗细及形状待定 |
| 角色关系 | 趴在贴纸上沿、从标题旁探头，或抱着主贴纸 |
| 字体 | 数字保持清晰稳定，手绘装饰主要放在角色与边缘 |
| 动效 | 角色可有少量状态动作，是否加入、何时触发及频率待定 |

用户对当前绿色方案的不认可，不等于永久禁止所有绿色点缀；应先用视觉方案确认新的整体色彩。
