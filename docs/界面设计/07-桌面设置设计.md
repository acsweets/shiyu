# 桌面设置设计

日期 2026-11-05。Windows 桌面试用版。设置窗采用统一白底、粗体文字和陶土色点缀。

## 窗口和页面

从主浮窗的齿轮或托盘进入独立设置窗。再次打开时聚焦已有设置窗，桌面浮窗可在旁边实时展示修改结果。左侧导航始终可见，右侧内容单独滚动。首次打开进入「外观」。

| 页面 | 内容和优先级 |
| --- | --- |
| 外观 | 左侧展示三张配色色卡和提示文字大小，右侧用真实猫猫、色板和倒计时样例预览。窄窗将预览移到控件下方。 |
| 窗口管理 | 一行呈现一个窗口及其倒计时。显示窗口、显示标题和缩放在窗口内部操作。每项倒计时旁有「移到…」。 |
| 倒计时 | 主倒计时通过下拉选择，启用列表用开关。退休日期与时区作为一组编辑并保存。 |
| 猫猫素材 | 按窗口编号预览四种姿态，提供打开素材目录、重新载入和文件命名说明。 |

## 视觉和控件

- 标题区、侧栏、内容区、预览外框和底部反馈统一使用白底 `#FFFFFF`。正文用深棕 `#332B26`，陶土色 `#854A39` 用于选中态和主要动作。预览中的倒计时卡片显示实际配色。
- 标题、正文、说明、按钮及菜单统一使用粗体。字号、留白和颜色用于区分层级。正文左右各留 32 逻辑像素。
- 配色色卡等宽，卡间留 14 逻辑像素。卡内左右各留 14，标签与色带之间留 10。窄窗口按可用宽度换行。
- 用标题、留白和细分隔线组织内容。常规控件高约 36–40 逻辑像素，边角约 8–10，菜单用轻阴影表现层级。
- 主按钮使用陶土色实底和白字，按钮名说明动作，例如「保存退休设置」。次按钮使用白底与细描边。悬停、按下、禁用和键盘聚焦都有可辨认的状态。
- 下拉控件显示当前值与下箭头，菜单贴着触发器打开。当前项带勾，悬停项用浅杏色。方向键移动焦点，回车选择，Esc 收起。短选项用单选菜单，窗口目标同时显示编号和内容。
- 显隐用开关，三套配色直接展示样本与选中标记。外观及开关修改后立即应用并保存。日期和时区在各自表单内保存。

## 合并与拆分

1. 打开「窗口管理」，从现有窗口列表找到目标倒计时。
2. 点该倒计时旁的「移到…」，选已有窗口即可合并，选「新的独立窗口」即可拆分。
3. 列表和桌面浮窗同步更新，结果条提供一次撤销。
4. 重置仅恢复窗口位置和尺寸，触发前明确显示确认。关闭设置窗即退出设置。

## Windows 试用检查

- [ ] 从齿轮和托盘打开设置，连续打开时只出现一个设置窗。
- [ ] 切换色卡、拖动字号滑块，预览及现有浮窗更新。
- [ ] 检查白底、统一字重和色卡留白。缩窄窗口后确认色卡能换行，预览可滚动查看。
- [ ] 使用鼠标和键盘打开、选择和关闭下拉菜单。
- [ ] 合并、拆分和撤销后，窗口列表与桌面上的实际窗口一致。
- [ ] 窗口关闭后可从托盘进入设置并重新打开。重置前有确认。
- [ ] 检查退休设置校验、编号素材预览和重新载入入口。

## 开发者验证

- Windows Release 从主浮窗打开设置，原生关闭后再次打开复用同一窗口。设置窗获焦时显示在浮窗上方，失焦时让出层级。
- 实测外观预览换色、带焦点的下拉菜单、方向键及回车拆分、撤销恢复分组，以及四种编号素材的预览。
- Windows Release 核对外观和窗口管理的白底、粗体及菜单样式。Flutter 测试覆盖统一字重、色卡等宽和卡间距。
- `scripts/check.ps1 -BuildWindows` 和 Windows 退休设置集成测试通过。macOS 待实测。
