# 桌面浮窗分组

日期 2026-11-05。这一版支持把已开启的倒计时分别放在各自的系统窗口，或合并到同一个窗口。

## 操作方式

1. 点击任意浮窗右上角的设置按钮。在“窗口分组”下，为需要合并的倒计时选择同一个目标窗口。
2. 在下拉列表中选择“独立窗口”，即可单独拆出该倒计时。每个已开启的倒计时只在一处显示。
3. 拖动窗口顶部的把手移动整窗，拖动右下角调整宽高。设置里也可按窗口放大或缩小，主窗的大小会在关闭设置后应用。
4. 关闭对应窗口的“显示标题”可同时隐藏窗内标题栏文字和各项倒计时名称。完整时间、示例标记、拖动把手和设置入口仍可使用。

最小尺寸为 260 × 146 逻辑像素。加宽窗口会增加列数，加高可查看更多行。暂时放不下的项目可以在窗内滚动。主窗关闭按钮收起全部浮窗，托盘或 Ctrl/Cmd+Shift+T 可恢复。外围窗口的关闭按钮关闭该组的显示开关，可在设置中重新开启。

各组位置、尺寸、标题开关和归属保存在外观目录的 layout.json。旧版画布位置用作首次独立窗的初始位置。真正在运行的退休倒计时仍由主引擎的 Rust 快照提供，各窗共用这一数据源。

## 验证

- Flutter 测试覆盖旧配置迁移、合并/拆分持久化、同窗完整时间和隐藏标题。
- Windows Release 实测四个独立窗口，合并下班与放假后为三个，拆出放假后恢复四个，再次合并后为三个。
- 实测右下角缩至 260 × 146，设置内放大后两项并排显示。关闭标题后两组时间仍完整可见。
- 实测独立拖动退休窗，布局文件保存其新位置，其他窗口几何信息不变。
- Windows 通过 `scripts/check.ps1 -BuildWindows`，包括 6 项 Flutter 测试、Release 构建和 9 项 Rust 测试。Windows 真实退休设置集成测试也通过。
- macOS 已接入多窗注册，待在 Mac 构建与实测。

系统子窗使用 [desktop_multi_window](https://pub.dev/packages/desktop_multi_window/versions/0.3.1) 创建，设置与 Rust 快照由主引擎管理。
