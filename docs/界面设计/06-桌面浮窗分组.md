# 桌面浮窗分组

日期 2026-11-05。这一版支持把已开启的倒计时分别放在各自的系统窗口，或合并到同一个窗口。

## 操作方式

1. 点击主浮窗右上方的设置图标，打开独立设置窗并进入「窗口管理」。每个窗口列出当前的倒计时。
2. 点击倒计时旁的「移到…」。选择已有窗口可合并，选择「新的独立窗口」可拆出。移动后可立即撤销。
3. 拖动倒计时卡片移动整窗，鼠标移至右下角出现缩放指针时可拖动调整宽高。在窗口管理也可按窗口放大或缩小。
4. 关闭对应窗口的“显示标题”可隐藏各项倒计时名称，完整时间仍可见。
5. 关闭「显示窗口」会立即隐藏对应浮窗，保留位置、尺寸和归属。主窗隐藏后，可从系统托盘或菜单栏打开设置。
6. 在「外观」中点选马卡龙色系、冷酷色系或日落暖调。每套色卡展示各窗口的底色，预览和桌面浮窗实时换色。
7. 在“提示文字大小”中拖动滑块，可预览并调整“距离下班”等标题的字号。范围为 10–24，默认 13，所有浮窗同步应用。倒计时数字使用原字号。

每个浮窗的猫猫都贴住卡片上沿。窗口 1 至 4 分别使用坐姿、伸懒腰、挥爪、蜷睡。同窗的倒计时共用一只猫，合并后使用目标窗口的姿态，拆出后使用新窗口的姿态。设置图标只在主窗显示，示例状态可在设置中查看。替换猫猫的文件要求见[资源制作指南](04-用户资源制作指南.md)。

最小尺寸为 260 × 146 逻辑像素。加宽窗口会增加列数，加高可查看更多行。暂时放不下的项目可以在窗内滚动。Ctrl/Cmd+Shift+T 可统一收起或恢复已开启的浮窗。

配色、提示文字大小和各组位置、尺寸、窗口与标题开关及倒计时归属保存在外观目录的 layout.json。旧版布局默认使用马卡龙色系和原字号，旧版画布位置用作首次独立窗的初始位置。真正在运行的退休倒计时仍由主引擎的 Rust 快照提供，各窗共用这一数据源。

## 验证

- Flutter 测试覆盖旧配置迁移、合并和拆分、保存窗口和标题显隐、四个窗口姿态、主窗和子窗的猫猫位置，以及同窗完整时间。
- Windows Release 实测四个独立窗口，合并下班与放假后为三个，拆出放假后恢复四个，再次合并后为三个。
- 实测右下角缩至 260 × 146，设置内放大后两项并排显示。关闭标题后两组时间仍完整可见。
- 实测独立拖动退休窗，布局文件保存其新位置，其他窗口几何信息不变。
- 精简界面后在 Windows Release 核对主窗猫猫和设置图标、子窗标题与完整倒计时，并实测在设置中隐藏、恢复发薪窗以及拖动其卡片。
- Windows 通过 `scripts/check.ps1 -BuildWindows`，包括 6 项 Flutter 测试、Release 构建和 9 项 Rust 测试。Windows 真实退休设置集成测试也通过。
- Windows 集成测试覆盖主窗启动时保持隐藏、经托盘设置入口恢复显示。
- Windows Release 实测三张色卡预览与切换。冷酷色系同步应用到主窗和子窗，重启后保留。Flutter 测试覆盖旧布局的默认配色、色卡点击及窗口底色更新。
- Windows Release 逐窗查看四个独立浮窗，确认坐姿、伸懒腰、挥爪、蜷睡分别显示在卡片上方，设置图标只在主窗。Flutter 测试还覆盖旧主窗图片和编号图片的读取。
- Windows Release 核对四种姿态均轻压卡片上沿。Flutter 测试检查最小窗的贴纸轮廓与上沿的重叠量，以及自定义 PNG 的透明留白测量。
- Windows Release 实测将提示文字从 13 调至 24，主窗和子窗同步放大，最小窗仍完整显示标题与倒计时，重启后保留字号。Flutter 测试覆盖旧配置默认值与字号保存。
- macOS 已接入多窗注册，待在 Mac 构建与实测。

系统子窗使用 [desktop_multi_window](https://pub.dev/packages/desktop_multi_window/versions/0.3.1) 创建，设置与 Rust 快照由主引擎管理。
