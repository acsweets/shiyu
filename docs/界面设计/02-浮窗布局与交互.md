# 02：浮窗布局与交互

[设计目录](README.md)

状态：核心结构已确认，具体交互待讨论。日期：2026-11-04。

## 单个内容的结构：已确认

每个倒计时内容采用上下结构：

1. 上方为标题，说明正在倒数什么。
2. 下方为一组完整、连贯的倒计时，数字和单位共同构成完整表达。

例如“距离下班”下面显示“02小时 36分 18秒”；这是排版示意，不是当前业务计算结果。时间不拆为多个独立数字格，也不将天数单独放大后把其余时间放到另一个区域。

具体采用天/时/分/秒、年/月/天或其他完整表达尚待确认。外围贴纸同样遵守完整显示要求，长文本和空间不足时的适配方式需要通过设计稿确定。

## 整体关系：已确认

- 有一个主倒计时，作为整组浮窗的视觉中心。
- 其他倒计时开启后，显示在主倒计时周边，形成围绕主内容的贴纸组合。
- 用户能够自行拖动摆放外围贴纸，安排自己想要的位置。
- 主次关系通过设计表达；具体大小比例和周边分布形态尚未确定。

这轮确认不要求外围贴纸固定为纵向列表、横向列表或均匀圆环。

## 交互细节：待确认

| 议题 | 需要决定的内容 |
| --- | --- |
| 主指标 | 默认哪个指标；是否可自由指定；如何更换 |
| 新开启的贴纸 | 初始出现在哪里；与用户已有摆放如何协调 |
| 拖动入口 | 常态直接拖动，还是进入布局编辑模式；可拖动的区域 |
| 整体移动 | 主贴纸移动时，其他贴纸是否一起跟随；是否另有整组移动入口 |
| 相对位置 | 外围位置以主贴纸还是屏幕为参照；主指标更换后如何处理 |
| 重叠与边界 | 是否允许覆盖；是否限制出屏；怎样找回被遮挡或越界的贴纸 |
| 保存与恢复 | 重启是否恢复布局；关闭再开启某个指标是否回到原位置 |
| 复位与撤销 | 是否提供布局复位、单项复位或拖动撤销 |
| 多屏与缩放 | 更换屏幕、分辨率、系统缩放后如何保持可见与可读 |
| 长倒计时 | 字号、贴纸宽度与完整表达如何协调，避免裁切时间信息 |
| 设置入口 | 设置是否单独打开，按钮在何时显示 |
| 三态关系 | 原冻结需求中的迷你／标准／展开态如何与新布局结合 |

此前助手提出“拖动主贴纸时整组一起移动”“默认距离下班”等建议，用户尚未单独确认，不能直接作为实施规格。
