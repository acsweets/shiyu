# 03：贴纸资源与替换

[设计目录](README.md)

状态：可替换方向已确认，资源规格待设计。日期：2026-11-04。

## 已确认

贴纸需要按**未来可以替换的资源**设计。当前先记录这个约束，后续设计和实现需要为替换留出边界。

本次没有确定资源包格式、生成素材或实现导入功能；用户也尚未决定是逐张替换、整套替换，还是两者都支持。

## 建议的拆分方式：待确认

| 层次 | 候选内容 | 用途 |
| --- | --- | --- |
| 贴纸背景与边缘 | 纸张底、轮廓、描边、投影 | 提供内容容器的外观 |
| 角色与装饰 | 小角色、角落装饰、状态动作 | 表达 Q 版风格和角色特点 |
| 动态内容 | 标题、完整倒计时、后续其他真实指标 | 由界面实时呈现，避免将会变化的数值画死在图片里 |
| 资源描述 | 内容安全区、角色位置、缩放规则、适用主/外围规格 | 使不同资源能够正确容纳同一内容结构 |

这是建议的资源边界，不是已经冻结的文件格式。背景与角色是否拆成独立文件、是否使用透明位图及如何适配尺寸，需结合选定的设计稿决定。

## 需要与布局协调的事项

- 更换贴纸时，标题和完整倒计时需要保持可读，角色不能占用必要的内容空间。
- 主贴纸与外围贴纸是否共用资源、是否需要不同尺寸版本，尚待确定。
- 装饰轮廓、实际内容范围与可拖动范围需要分别考虑，避免透明边缘妨碍其他贴纸操作。
- 更换资源是否保留用户摆放、资源尺寸变化时怎样处理位置，尚待确定。
- 原有皮肤/资源包需求仍保留；这里不另建一套未经讨论的平行机制。
