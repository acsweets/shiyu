# 05：桌面猫猫贴纸首版

后续已改为可合并、拆分的系统窗口，当前操作见[桌面浮窗分组](06-桌面浮窗分组.md)。

日期：2026-11-05。用户要求先做一版桌面效果，允许恢复本次桌面界面实现；后续指标节点仍暂停，等待界面反馈。

## 当前交付

- 桌面独立使用透明贴纸画布：主贴纸带猫猫，其他开启的贴纸分布周围。
- 每项上方标题、下方完整时间，保持同一行数字与单位；长时间按整体缩小适配，不拆成数字格。
- 主贴纸和外围贴纸均可在画布内拖动；贴纸移动保持相对独立。顶部工具条用于移动整个窗口。
- 设置面板支持主倒计时选择、单项开关、恢复排布、真实退休日期/时区、角色素材目录与重新载入。
- 排布、主项、开关与预览偏好独立原子保存到应用数据目录 `shiyu/appearance/layout.json`，不改变 Rust 设置契约。
- 内置猫猫为独立透明 PNG，可用外观目录中的 `character.png` 覆盖；缺失、超出 8 MiB 或解码失败时回退内置图。整包导入与底板替换尚未实现。

## 示例与真实数据

首次进入桌面效果预览，顶部、底部和每张贴纸均标明示例。示例时间为固定排版数据，不计时，不保存为用户业务输入。设置中关闭“效果预览”后，退休指标读取现有真实 Rust 秒数并格式化为完整倒计时；其他指标显示待接入。

想看真实运行时，在设置中关闭预览、将主项选为距离退休，再设置自己的退休日期。到期显示已退休，未配置时提示设置。移动端入口与原生 Widget 未在本次重做。

## 本版实现选择与限制

这些是首版供用户试用的实现选择，等待用户反馈后再定稿。

- 760 × 560 的透明窗口画布，贴纸位置限制在画布内；允许贴纸相互覆盖，主贴纸位于上层。
- 透明空白区域仍属于窗口，尚未做按像素鼠标穿透；不属于多个完全独立的系统窗口。
- 本版桌面设置与工具条先提供中文，不宣称新界面已完成八语言。
- 主倒计时默认距离下班（示例），可以自由更换；切换时保留主贴纸位置，布局支持复位。
- 外围底板目前由界面形状绘制；猫猫是独立生成素材，底板 PNG/整套 timerpack/动画仍待后续设计。
- Windows 实测；macOS 复用代码，需用户在 Mac 构建验证。
