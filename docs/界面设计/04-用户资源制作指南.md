## 替换单个窗口的猫猫

1. 新建透明画布，建议 1024 × 1024 像素、sRGB、8 位 RGBA。只画角色本身，留出耳朵、胡须和尾巴所需空间。
2. 导出静态 PNG。保持真实 Alpha 透明通道。建议将可见部分离边缘至少 64 像素，避免另画地面、底板、数字或水印。
3. 在桌面设置打开「猫猫素材 → 打开素材目录」。把图片命名为 `character-1.png` 至 `character-4.png`，编号对应设置中的窗口，单张最多 8 MiB。
4. 点「重新载入猫猫」。应用按原始比例缩放，并用透明通道定位角色下沿。主窗仍兼容旧的 `character.png`。删除对应替换文件并重新载入即可恢复资源包素材或内置姿态。

在白色、深色和马卡龙背景上检查透明边缘，也要在最小浮窗上看角色和完整时间行是否清晰。底板由两套内置模板绘制，可从设置调整色卡、明暗、透明度和强调色。

## 制作和分享皮肤包

从「猫猫素材 → 导出皮肤包」生成 `.timerpack`。包中记录当前皮肤、整窗色卡、明暗模式、背景不透明度、倒计时数字字号、强调色和正在使用的替换素材。窗口坐标、分组、个人设置和薪资留在本机。

如需手动制作，使用 ZIP 工具把以下内容直接放在归档根目录，再使用 `.timerpack` 扩展名。采用普通单卷 ZIP，压缩方法可用 STORE 或 DEFLATE。

```text
manifest.json
cats/
  character-1.png
  character-2.png
```

```json
{
  "schema_version": 1,
  "appearance": {
    "skin": "stationery",
    "theme": "light",
    "opacity": 100,
    "scale": "medium",
    "accent": null
  },
  "palette": "macaron",
  "assets": ["cats/character-1.png", "cats/character-2.png"]
}
```

| 字段 | 可用值 |
| --- | --- |
| `skin` | `stationery`（简约卡片）、`darkTech`（深色科技） |
| `theme` | `light`、`dark`、`system` |
| `opacity` | 30–100 的整数百分比 |
| `scale` | `small`、`medium`、`large` |
| `accent` | `null` 或以下 ARGB 值对应的十进制整数。暖橙 0xFFE7A976、浅蓝 0xFF91B6E0、淡紫 0xFFB39AE2、薄荷 0xFF83C4B0 |
| `palette` | `macaron`、`cool`、`sunset` |
| `assets` | 已放入包内的 `cats/character-1.png` 至 `cats/character-4.png`。只分享配色时用 `[]` |

清单采用 UTF-8，最多 16 KiB。压缩包最多 8 MiB，解包总量最多 6 MiB。每张 PNG 最多 2 MiB，长宽各不超过 2048 像素。应用校验允许的路径、ZIP 校验码、清单字段、PNG 格式和实际解码结果。损坏包、未知版本、目录穿越、链接、脚本、动画图、缺失文件和未声明的条目会被拒绝。导入失败会保留现有皮肤。

在「猫猫素材 → 导入皮肤包」选择文件，也可使用系统文件关联打开。macOS 应用声明了该文件类型。Windows 从仓库根目录运行 `./scripts/register_timerpack.ps1 -Executable 'C:/path/to/shiyu.exe'` 为当前用户登记；已有其他关联时在“打开方式”选择时余。

素材目录里手动放置的编号 PNG 优先于资源包。恢复默认皮肤会恢复默认设计令牌并停用资源包，手动素材仍由对应文件控制。

只分享自己制作或经许可允许再分发的资源。随分享链接另附作者、来源、许可证与改作授权。素材授权说明随包发布在外部页面或文档中，包内只保留清单和受支持的 PNG。
